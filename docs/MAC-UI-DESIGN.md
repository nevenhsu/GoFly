# Mac 介面精修規格

2026-10-22 行為更新：重新簽名／更新也須核對並交付所選 iPhone 的配對資料與必要裝置準備，手機精確回報後才顯示完成；覆蓋保留偏好、最愛、路線，不卸載或重置。這取代「renew 只有 artifact／install 即成功」的實作規則。目前完整交接實作限 USB；以下 Wi‑Fi 更新簽名仍屬待實作設計。舊版簽署完成回報不視為目前已備妥配對。


確認日期：2026-10-18。依使用者要求直接精修 `app/GoFlyMac`，延續 GoFly 黑白風格；Figma 線框不在本次修改範圍。

## 視覺與平台適配

- 文字採 macOS 內建系統字體，中文交由系統選擇字形；標題 semibold，內文 regular。不再註冊或指定 Noto Sans TC。
- 視窗跟隨系統深淺色。背景、側邊欄、卡片、文字與分隔線採 AppKit 語意色；主操作以高對比黑白反轉呈現。
- 內容卡片採 16 pt 連續圓角、內嵌群組 12 pt、按鈕與輸入框 10 pt。卡片內距 24 pt、主內容水平內距 32 pt，間距以 4 pt 為基準。
- 視窗至少 1000 × 700 pt，預設 1120 × 760 pt。內容可捲動，主要導覽與頁尾留在固定區域；避免卡片內再套垂直捲動。
- 裝置、USB、Wi-Fi 與環境使用 SF Symbols，保留 GoFly 品牌圖形。裝飾圖示不重複朗讀，圖示不單獨承擔狀態含義。

## 共用元件與內容

- 側邊欄以反差底色標示目前頁；首次安裝保留步驟序號，裝置管理使用功能圖示。導覽與裝置切換繼續遵守操作鎖。
- 主次按鈕統一圓角、hover／pressed／disabled 狀態與鍵盤焦點外框；原生 Picker、checkbox、檔案選擇器維持 macOS 操作方式。
- 淺色輸入框使用明確灰底與灰色邊線，焦點時加深加粗邊線；輸入框都有常駐標籤，不能只靠 placeholder 辨識。
- Team 在 Mac 環境引導中選擇：1 個 Team 自動選取；多個顯示選單，每項標出「個人（免費，簽名 7 天）」或「團隊」。安裝頁只顯示目前 Team，不提供 Team 輸入框。
- 裝置列以勾選圖示和邊框共同表示選取，連線通道採具文字的 USB／Wi-Fi 標章。裝置去重與通道選擇仍由既有 model 決定。
- 安裝表單只剩確認內容：裝置名稱、iOS 版本、目前 Team 與開始按鈕；不顯示 Team ID 輸入框、安裝來源或交易細節。進入確認頁自動執行 preflight，不提供「唯讀檢查」按鈕。
- 首次安裝以 4 步呈現：選擇 iPhone、確認、安裝進度、完成；完成頁顯示簽名到期日與「先開啟 LocalDevVPN，再開啟 GoFly」。
- 裝置頁顯示手機上 GoFly 的版本／build、Mac 專案的版本／build、簽名到期日與剩餘天數；選取裝置不自動寫入，主按鈕依版本顯示「延長簽名期限」或「更新 GoFly」。
- renew 完成頁顯示新的簽名到期日與「手機上的資料和設定已保留」。

## 行為與驗收

文案必須描述可核對的狀態，例如「尚未完成」「結果待確認」；只有既有 model 提供完成證據時才顯示「完成」。錯誤提供原因與既有處理入口，不用裝飾性圖示取代說明。

- 啟動時先顯示「正在檢查 Mac 環境」；全部通過才進首頁，未通過時停在第一個失敗步驟，一次只顯示一個步驟，每步都有「重新檢查」。
- Xcode 未安裝、首次啟動未完成或沒有 Apple 帳號時，只提供 App Store／開啟 Xcode 的入口與說明；不顯示 Apple ID 或密碼輸入框，也不代替使用者執行系統授權。
- 首頁的「Mac 環境」標籤顯示 Xcode 版本、Apple 帳號狀態、目前 Team 名稱與類型；點開顯示完整檢查並可更換 Team。
- 環境或 bridge 無法使用時，首頁與環境頁顯示可區分的原因：App 資源設定失敗（提示重新執行 `build-app.sh`）或 Python 環境無法使用。不得只顯示「尚未就緒」。
- 環境未就緒時，首頁、查看 Mac 環境與返回裝置清單等純導覽入口仍可使用；只有會檢查或寫入裝置的操作才受 readiness 限制。
- 首次安裝若確認這部 iPhone 已安裝 GoFly，顯示「此 iPhone 已安裝 GoFly，請到裝置管理重新簽名」與前往該裝置頁的按鈕，不以通用安裝錯誤取代。
- 已完成的 setup journal 不得鎖住導覽或顯示續接；只有尚未完成的交易才顯示續接入口。缺少 `mode` 的舊 journal 視為首次安裝。

禁止固定白底／黑字、僅靠低對比底色表示選取、以 placeholder 取代標籤，或將長說明截成一行。舊元件依共用 token 遷移，不能另外建立相近但不一致的配色。

本次為 App 視覺與可用性更新；不改變簽署授權、交易接續或完成判定。沒有介面預覽；畫面只顯示 bridge 與本機交易實際回報的狀態。

驗收：首頁、裝置清單、環境與安裝的層級一致；深淺色可讀；選取與 disabled 可辨識；鍵盤可聚焦控制項；1000 × 700 pt 下長說明可捲動且操作可達。編譯／離線測試與實機驗收分別記錄。手機、DMG 與真實簽署的既有驗收規則仍適用。

驗證證據另存 `work/gofly-mac/design-polish/RESULT.md`；沒有證據的項目維持未驗。

### 共用版面

- 視窗 1120 × 760：左側 240 pt 側欄（GoFly、首頁／Mac 環境／首次安裝／裝置管理／備份），流程中的側欄下方顯示步驟（完成＝綠色 ✓、目前＝黑底）；裝置管理與備份頁的側欄下方顯示裝置清單與「↻ 重新搜尋」。
- 內容區：麵包屑、28 pt 標題、說明、卡片；底部固定分隔線與右對齊按鈕，主要按鈕在最右。
- 狀態一律用 StatusBanner（danger／warning／success／資訊，圖示＋文字），與 iOS 改版同一套語意色。
- **系統視窗引導**：macOS／Xcode／iPhone 會跳出系統視窗的步驟，左側寫編號步驟，右側放「你會看到的視窗（示意）」插圖，以橘色框與「點這裡」標出要點的按鈕。GoFly 不代替使用者點擊、安裝、接受條款或輸入密碼；文案要區分「Mac 登入密碼」「iPhone 密碼」「Apple 帳號密碼」。

### M1 Mac 環境設定（E01–E08）

- 啟動自動檢查：Xcode → 命令列工具 → Xcode 元件與 iOS 平台 → Apple 帳號 → 開發團隊 → App 資源與 Python 環境。全部通過直接進首頁；否則一次只顯示第一個未通過的步驟，每步都有「重新檢查」。
- 需要引導的系統視窗：命令列工具安裝視窗（點「安裝」）、Xcode 授權條款（點「同意」並輸入 Mac 登入密碼）、Xcode 平台選擇（勾選 iOS、點「下載並安裝」）、Xcode › Settings › Accounts（點「+」新增 Apple Account）。
- Team 只有 1 個時自動選取並略過；多個時列出並標示「個人（免費・7 天）」或「團隊」。
- App 資源或 Python 環境失敗要顯示可區分的原因（重新執行 `build-app.sh`、建立 Python 環境），不只寫「尚未就緒」。

### M2 首次安裝（I01–I09，僅 USB）

- 步驟：連接 iPhone → 信任這部 Mac → 開發者模式 → 確認 → 安裝 → 完成；已完成的步驟自動略過。
- 需要引導的系統視窗：iPhone「要信任這部電腦嗎？」（點「信任」並輸入 iPhone 密碼）、iPhone 開發者模式（設定 › 隱私權與安全性 › 開發者模式 → 重新啟動 → 點「開啟」）、Mac 鑰匙圈 codesign 視窗（輸入 Mac 登入密碼並點「永遠允許」）。
- 完成頁顯示實際讀回的簽名到期日，並列出 iPhone 上的下一步：個人 Team 需在「設定 › 一般 › VPN 與裝置管理」信任開發者（附「未受信任的開發者」視窗插圖）、安裝並開啟 LocalDevVPN、開啟 GoFly。
- 已安裝 GoFly 時顯示 I08 並帶到裝置管理，不以通用錯誤取代。
- **USB 中途斷線一律從頭重新安裝，不做接續**（2026-10-20 決定，取代「繼續上次安裝」）：I09 只提供「重新安裝」，重新觀察手機狀態後從第一步執行；GoFly 已裝上時改用覆蓋安裝，配對重新產生並先清除舊的未消耗配對。

### M3 裝置管理與備份（G01–G17）

- 裝置頁顯示手機上的 GoFly 版本／build、Mac 上的新版本、簽名到期日與剩餘天數、LocalDevVPN 狀態，以及三個動作卡：
  - **更新 GoFly（保留資料）**：安裝新版並同時更新簽名；確認頁列出保留清單（最愛地點、最愛路線、已匯入路線、設定與偏好、配對與啟用，能讀到時附數量）；USB 連接時更新前先備份；中斷時從頭重新更新。
  - **更新簽名（保留資料）**：只延長使用期限；版本一致時版本不變，不一致時經 G17 確認後覆蓋成 Mac 上的版本；可用 Wi‑Fi。
  - **重置 GoFly（不保留資料）**：刪除手機上 GoFly 的所有資料後安裝最新版本，配對與啟用由 Mac 重新匯入。「重置前先備份到這台 Mac」選填、預設勾選、可取消；「我了解 iPhone 上的資料會被刪除」必須勾選才能按紅色按鈕。完成後提示在 iPhone 重新完成首次引導，有備份時顯示備份位置。
- 主要按鈕依狀態：有新版本時「更新 GoFly」；版本相同或只需延長期限時「更新簽名」；重置永遠是次要動作。選取裝置不自動寫入。
- 「資料已保留」「新的到期日」只在 App／bridge 實際讀回後顯示；讀不到時寫「待確認」或「未取得」。

- **連線**：首次安裝、更新 GoFly、重置、立即備份、還原只限 USB；只有「更新簽名」可用 Wi‑Fi。Wi‑Fi 連接時其他動作停用並寫「需要 USB 連接」（G14）。
- **更新簽名**（G07、G17）：只為延長使用期限，可用 Wi‑Fi。版本一致時重新簽署同一版本，版本不變；手機與 Mac 版本不一致（或讀不到手機版本）時，先顯示確認步驟 G17（例如 build 21 → build 24），確認後直接覆蓋成 Mac 上的版本，資料保留。USB 時先備份，Wi‑Fi 時無法備份並明確告知。
- **未安裝 GoFly**（G15、G16）：選取的 iPhone 沒有 GoFly 時，更新、更新簽名、重置、立即備份、還原都停用，提示先完成首次安裝並提供「前往首次安裝」；備份列表仍可操作。
- **重新搜尋裝置**：側欄裝置清單右上「↻ 重新搜尋」，唯讀重新列出 USB／Wi‑Fi 裝置；搜尋中停用。
- **中斷**：所有動作 USB 中途斷線即停止，回來只能「重新開始」從頭執行，不做接續。
- **備份管理頁**（側欄「備份」，G09–G10）：備份存在這台 Mac、不分裝置、最多 5 份；新備份完成後自動刪除最舊一份，確認頁事先告知；備份失敗不刪舊備份。每筆顯示時間、來源裝置、GoFly build、各類別筆數與大小，可還原、在 Finder 顯示、刪除。「立即備份」需要 USB 連接的 iPhone，且 GoFly 已關閉。
- **還原**（G11–G13）：可還原到任何一支 iPhone；取代（不合併）最愛地點、最愛路線、已匯入路線與偏好設定；「還原前先備份目前資料」選填、預設勾選；「我了解目前的資料會被取代」必須勾選。Mac 傳送後由 iPhone 在下次開啟 GoFly 時驗證並套用，Mac 讀取 receipt 顯示「已套用」或失敗原因。

### 驗收（實作時）

- 每個系統視窗引導步驟都有插圖與「點這裡」標示，文案指明要輸入的是哪一種密碼。
- USB 中途斷線時，首次安裝、更新、重置、備份、還原都停止，回來只能「重新開始」；重新開始前重新觀察手機狀態，不會套用舊交易的配對。
- 重置與還原需要二次確認；更新、更新簽名、重置（勾選備份時）、還原後資料讀回一致。
- 更新簽名：版本一致時版本不變；不一致時一定先出現確認步驟。
- Wi‑Fi 連接時只有更新簽名可用；未安裝 GoFly 時所有寫入動作停用並引導首次安裝。
- 備份最多 5 份，第 6 份完成時刪除最舊一份並事先告知；備份失敗不刪舊備份。
- 1000 × 700 pt 下內容可捲動、底部按鈕可達；深淺色皆可讀。
