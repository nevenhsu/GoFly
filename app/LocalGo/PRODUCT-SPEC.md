# LocalGo 功能與驗收狀態

使用者要求獨立開發自用 App，目標 iPhone 15／iOS 27、向下支援 iOS 26，Mac 用於首次設定，之後手機操作並改變多個其他 App 收到的位置。不連接原廠商服務。使用者已同意另裝 LocalDevVPN；免費簽署仍有有效期，不能承諾永久免續簽。

AnyGo 研究基準為 Mac 8.4.1 及 manifest 指向的 Std 1.2.4/build 138。Std 明示 Native 權限限制；未取得官方 Native 通道樣本，不能合併不同版本的能力或宣稱完全等效。

| 能力 | LocalGo 實作 | 驗收狀態 |
| --- | --- | --- |
| 地圖／地址與座標搜尋 | SwiftUI Map、MapKit 搜尋，座標範圍檢查、選點與接受位置分別顯示 | 已編譯；地圖網路及實機互動待驗 |
| 目前位置／方向 | 已接受位置優先，否則使用前景手機定位；無外框箭頭、移動方向、回到目前位置；僅按按鈕時請求使用期間授權 | 方向核心測試通過；授權、箭頭與地圖旋轉互動仍需手機確認 |
| 單點瞬移 | 真實裝置服務 adapter，服務回覆／失敗／清除狀態 | 使用者已確認拔 USB 後兩個其他 App 接收目標位置 |
| 兩點／多點路線 | 最多 25 個手動途經點、直線插值或 Apple 步行道路；開始／暫停／繼續／往返 | 排程測試通過；道路 API 與實機待驗 |
| 速度 | 2–100 km/h，步進 1，預設 20，快捷 5／20／60（內部換算為 m/s） | 已接路線與搖桿；實際裝置速度待驗 |
| 搖桿 | 方向、力度與速度、放開停止送點 | 排程／準備狀態測試通過；實機待驗 |
| GPX | 自行實作 GPX 1.1，2 MiB／10,000 點，track／route／waypoint，座標與 XML 限制 | 編解碼與不安全輸入測試通過 |
| 收藏／歷史 | 本機各最多 100 筆、重選／刪除、私有檔案原子儲存 | 儲存與失敗保護測試通過 |
| 停止／恢復 | 取消排程／作廢遲到回覆，呼叫 clear；失敗保持未知 | 使用者已確認停止清除後恢復真實位置；清除失敗仍需另驗 |
| 背景行為 | 路線暫停、搖桿停止送點，保留最後送出位置；手動繼續 | 排程測試通過；系統能否保留位置待驗 |
| 配對與裝置準備 | 私有 RP 自動交付／匯入、UDID 核對、DDI 準備、實際裝置服務 | iOS 27.0.1 匯入及準備通過；iOS 26 待驗 |
| 首次 Mac 自動設定 | 自有 USB RP 身分、Personal Team 簽署、精確裝置／簽章檢查、安裝、私密交付、交易回報 | 已在 iOS 27.0.1 成功完成安裝及匯入 |
| 手機獨立通道 | 開源裝置引擎、Mac 自動交付 RP、另裝 LocalDevVPN，無常駐 Mac tunnel | 使用者確認手機身分／DDI 已核對，拔 USB 後兩個 App 收到選定位置 |
| 通道提示 | 前景檢查固定本機通道；不可達時提示開啟 LocalDevVPN，連通後自動收起；不自動啟動定位 | 仍需手機切換 VPN 確認提示行為 |
| Native／所有其他 App | 不把服務 ACK 當作接收端效果 | 未驗證，不承諾所有 App |
| 重啟／網路恢復 | 失敗需清除並重新準備，不自動重播動作 | 未驗證 |

遊戲助手、修改版遊戲、第三方帳號與雲端同步未實作。GPX 使用自有格式實作，未複製廠商腳本。路線往返沿原路反向，不以終點瞬移回起點。排程僅前景運作，最多一個送點命令在處理；背景暫停不追補經過的時間。

## 服務與資料邊界

產品不呼叫 AnyGo／iToolab 的登入、啟用、配對下載或任何 API，不使用其固定身分、私鑰、憑證、IPA 或素材。原版樣本僅供 REA 研究，不進入 App bundle。

Apple MapKit 提供地圖、搜尋及道路規劃；DDI 由明示的上游來源在使用者要求準備時下載。RP 配對與個人簽章只用於指定裝置，配對不經廠商雲端或聊天交付。本機收藏／歷史與配對各自存放於私有空間，不記錄原始診斷。

## 成品仍需完成的驗收

iOS 26、27 各自在 iPhone 測試：首次設定、拔 USB 並停止 Mac、兩個獨立接收 App、單點／路線／搖桿、背景保留位置、Stop／clear 失敗、鎖屏、重啟、VPN 與網路切換。編譯成功、宿主測試通過或服務 ACK 皆不能代替以上結果。

目前交付包含功能原始碼及可重跑的 Mac 自動設定工具，已完成 iOS 27.0.1 實機簽署安裝／配對交付。48 項 Swift 核心測試、26 項 Mac 測試通過；使用者已確認拔 USB 後兩個 App 收到選定位置；也已確認停止後恢復真實位置；iOS 26 尚待驗收。另裝 LocalDevVPN 是使用者接受的架構變更，不能宣稱 App 已整合自己的 Network Extension。
