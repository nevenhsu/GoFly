## GoFly 瞬移互動定案（2026-10-17）

本節為使用者最終確認的開發需求。**目前只討論 UI／UX wireframe，不製作互動 prototype。** 2026-10-17 已清理 02 模組的互動接線及原型用重複狀態畫面，保留主要靜態 wireframe 與一張卡片狀態／title 範例；早先原型回測僅為歷史紀錄。瞬移、搜尋及最愛行為以本文件文字規格為準。Figma 仍提示部分變更待雲端同步，已另存本機副本。App 實作與實機驗收尚未依本次變更完成。以下既有能力表仍記錄 LocalGo 的實作及驗收狀態。相關設計紀錄見 [wireframe 複審](../../work/gofly-planning/WIREFRAME-REVIEW.md)、[flow 審查與核可決策](../../work/gofly-planning/TELEPORT-FLOW-REVIEW.md)，用語見 [GLOSSARY.md](../../work/gofly-planning/GLOSSARY.md)。後續確認設計或行為變更時，需同時同步相關開發文件與驗收條件。較早的 02 整理範圍不包含路線與搖桿；後續 03／04／06 定案見下節，最新規則優先。本輪仍只更新 Figma 與 docs，App 尚未依新 UI 實作。

瞬移流程為「指定候選目的地 → 更新並置中 Pin → 按 Go → 成功後更新模擬位置箭頭、移除 Pin」。選點、搜尋結果切換及輸入座標都不會自行執行瞬移。

| 操作／畫面 | 已確認行為 |
| --- | --- |
| D01／地圖選點 | 初始底部只保留模式列、搜尋欄與「☆ 最愛地點」，移除「尚未選擇地點」及「搜尋名稱、輸入經緯度，或在地圖選點。」；面板隨內容縮高、不留佔位。移除右上角的選點 pin 按鈕；手指直接點地圖即可指定瞬移目的地，同步經緯度並將候選 Pin 置中。右下角準心只將鏡頭移回目前位置。 |
| D08／名稱搜尋多筆結果 | 每筆結果使用統一地點選項卡，只顯示一個 title 與右側收藏星號；title 規則見下節。首次搜尋尚未選取時不顯示目的地 Pin；若原本已有 Pin，等待選擇時保留。選取後更新 Pin 並將鏡頭置中至候選目的地，保留結果列表供切換；切換其他地標時再次更新 Pin 並置中。 |
| D10／輸入有效經緯度 | 有效座標立即自動選取對應選項卡，更新目的地 Pin 並將鏡頭置中至該座標；不必再點一次選項，仍須按 Go 才移動。座標地點也提供空心／實心星號，點空心立即加入最愛，之後可另行編輯標籤。格式錯誤或超出座標範圍時保留上一有效候選、Pin、選取與收藏狀態，停用 Go；不套用或收藏無效輸入。修正為有效座標或明確選取另一有效地點後才恢復 Go。 |
| 從最愛選點 | 帶入所選項目的地點身分、座標、名稱與標籤，將候選 Pin 置中；每筆選取與編輯都對應原項目，不得導向共用的固定台北 101 範例。 |
| Go／瞬移完成 | 所有 Pin 上的按鈕一律寫 **Go**。使用目前選定的候選目的地，未啟動服務時自動啟動並完成必要準備後前往；頂部播放只啟動服務，不能隱含前往候選地點。成功後更新目前模擬位置箭頭，目的地 Pin 及其 Go 操作消失；完成畫面的箭頭置中於可見地圖。 |
| Go／執行及異常 | 同一流程呈現執行中、成功、失敗與位置待確認。執行中避免重複送出；失敗保留候選 Pin 供重試。回覆不明時保留最後已知位置與候選點，鎖定原 Go 並顯示位置待確認；返回地圖仍停用原 Go。確認未套用才可明確重試，確認成功才更新箭頭、移除 Pin；仍未知則由設定修復，不宣告成功或盲目重送。 |
| 到達後暫停／繼續 | 保留實際地點、座標與收藏狀態。若沒有新候選地點，不重新出現 Pin／Go；有候選地點則保留該候選，不回退至固定範例。 |

「置中」以頂部狀態卡與底部操作面板之間的**可見地圖區域**為準，適用名稱搜尋、有效經緯度、直接點圖及最愛四種選點入口；鍵盤或面板改變高度時需重新計算，避免 Pin 被遮住。候選目的地 Pin、目前模擬位置箭頭與地圖鏡頭分開管理：鏡頭移到候選地點不代表已改變模擬位置。這些規則適用瞬移；既有路線規則保留，路線與搖桿的移動規則不因本輪文案精簡改變；相關地點最愛入口同步短文案。

01／02／07 已依指定 ios-hig-design skill 排查，使用者已核可全部建議並要求一併套用 Figma。正常搜尋／候選／到達／暫停說明、收藏保留提示及重複返回移除，面板隨內容縮高；必要錯誤、空清單、執行中與位置待確認保留。地點最愛相關入口統一「☆ 最愛地點」，標籤編輯顯示「編輯標籤／標籤／取消／儲存」。D18 的初始／選取／收藏標題是設計規則註記，保留。D13 不另放「輸入經緯度」按鈕，統一搜尋欄本已支援座標；J01／J02 頂部只用「已暫停」，F07 未取得真實位置時顯示「目前位置／未啟動」，不把範例位置當成已知值。無效座標期間停用 Go 的明確決策取代舊可用性未定狀態，見 [01／02 核可紀錄](../../work/gofly-planning/ONBOARDING-TELEPORT-FLOW-REVIEW.md)。所有保留操作的設計命中區至少 44 × 44 pt；Go 與 Pin 的詳情操作區分離。不新增 prototype、資料或收藏排列副本，App 尚未依此實作。

搜尋無結果保留「找不到地點」與「換個關鍵字，或輸入座標。」；有搜尋欄清除 × 時不重複放清除大按鈕。[K02 空最愛](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=75-48928) 顯示「尚無最愛地點」並提供「搜尋地點」入口，不能用空白頁代替有效空狀態。最愛 sheet 用「關閉」回原面板，標籤儲存／取消仍回原清單。

### 開發驗收條件

1. D01 不顯示「尚未選擇地點」或重複搜尋教學，底部面板縮為 186 pt，保留模式／搜尋／最愛操作，不留空白佔位。直接點地圖可指定候選目的地；沒有右上角選點按鈕，且選點不發送瞬移命令。
2. D08 點選卡片的 title／選取區會選取該地點、收起鍵盤並顯示置中的 Pin；右側星號只切換收藏，不連帶選取。仍可在列表中切換地標。每次切換都更新候選目的地及鏡頭，按 Go 前目前模擬位置保持不變。
3. D10 輸入有效經緯度即自動選取對應卡片，更新並置中 Pin，不需再點選項；無效輸入保留前一次有效候選及其選取／收藏狀態，但停用 Go，且不發送瞬移命令；修正有效或明確選取另一有效地點後才恢復。錯誤需具體區分格式、緯度超界及經度超界，例如「經度須介於 −180° 與 180°。」
4. Go 執行的是最後選取的地標或有效座標；成功後箭頭更新至該位置並置中，目的地 Pin 與 Go 消失，鍵盤收起。不能把選取結果或輸入有效座標視為已完成瞬移。
5. 實作驗收需分別核對候選位置、服務接受的位置與接收 App 的實際位置；Figma 完成畫面與服務 ACK 不能代替實機結果。
6. 名稱搜尋、經緯度、直接點圖及最愛選點都置中候選 Pin；分別測試台北 101、台北車站、有效座標與兩筆不同最愛，選取／編輯／Go／暫停／繼續都保留正確身分。到達後無新候選時不重建 Pin／Go。
7. 已啟動與未啟動的 Pin 按鈕都寫 Go；未啟動按 Go 會先準備服務再前往同一候選點，頂部播放只啟動服務。執行中重複點擊不多送命令；失敗可保留候選重試，回覆不明先核對而不直接判定成功。

## 02 模組地點選項卡定案（2026-10-17）

使用者已確認統一「02 · 瞬移：搜尋、選點與最愛」的地點選項卡，含初始搜尋、保留原候選時的搜尋、選取後可切換結果、有效座標及最愛列表。本次已透過 **Figma Desktop Bridge** 套用至本機靜態 wireframe；保留 [D18／四種狀態與 title 範例](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=69-37851)。本節取代舊「名稱＋地址兩行卡片」、結果膠囊與最愛純文字選取列；路線、來回走動、漫步與搖桿的既有共用元件不修改。App 尚未依此實作，雲端同步仍待確認。

- 所有地點選項採同一款圓角矩形卡片。Figma 線框尺寸為 337 × 56 pt、圓角 12 pt；title 靠左，最右側固定 44 × 44 pt 的星號操作區。長 title 單行截斷，不能擠壓或遮蔽星號；完整地點資料仍保留，不以截斷文字識別地點。
- 卡片只顯示**一個 title**：有名稱用名稱；無名稱時用地址；名稱與地址都沒有時用經緯度。**直接輸入經緯度時顯示經緯度**，不因反查取得名稱或地址而替換輸入的座標 title。不另顯示地址副標，也不在名稱後拼接地址。
- 「初始／未選取」使用一般底色與淡色外框；「目前選取」使用強調外框與淡底色。兩者的形狀、尺寸與 title／星號位置完全相同；切換結果不再換成膠囊或無框文字。
- 選取狀態與收藏狀態互相獨立，共有未選取 ☆、未選取 ★、已選取 ☆、已選取 ★ 四種組合。星號代表收藏，不代表目前選取；收藏星號以既有地點身分與座標對應的最愛紀錄為準。
- 點 title／卡片選取區只更新候選地點、選取樣式與置中 Pin，須按 Go 才瞬移；星號具有獨立點擊區，只立即加入／移除最愛，不冒泡觸發選取、不切換候選、不改變 Pin 或模擬位置。**標籤編輯只放在最愛清單：長按某筆地點列，開啟該筆的 Label input 與鍵盤**；搜尋結果、候選、座標及到達卡片都不顯示「編輯標籤」按鈕。編輯不是加入最愛的前置步驟。
- 搜尋欄下方不顯示「輸入名稱或『緯度, 經度』」標題與「輸入名稱會列出地標；選定後才更新 Pin。」說明文字，移除文字後面板隨內容縮高，不留空白佔位。輸入提示由搜尋欄本身呈現；這項精簡不改變名稱選取後更新 Pin、有效經緯度自動選取的規則。
- 首次名稱搜尋且沒有候選地點時，不預選結果。若已有候選，繼續顯示其選取狀態與 Pin；切換其他結果才更新候選。**有效經緯度輸入後則自動選取其卡片**，同時更新並置中 Pin；不需再點卡片，也不自動執行 Go。格式錯誤或超出範圍時保留前次有效候選、選取樣式、Pin 與其收藏狀態，停用 Go，不將錯誤輸入當成新選項；修正有效或明確選取其他有效地點後才恢復 Go。
- 最愛列表共用相同地點卡片；目前候選若在列表內，使用相同選取樣式。移除只影響該最愛，保留其他項目與候選；清單逐筆條列地點，不另放逐筆「編輯標籤」按鈕；**短按選取目的地，長按地點列編輯 label**，右側星號獨立加入／移除最愛，不觸發長按編輯或選點。模式切換、搜尋輸入與 Go 保留操作按鈕用途。

驗收應覆蓋：名稱／無名稱地址／僅經緯度／直接輸入經緯度四種 title 情境；初始搜尋及目前選取 × 收藏的四種外觀；點未選項星號後候選不變；點 title 後只更新 Pin；有效座標自動選取與無效座標保留前值；切換選項、進出最愛及編輯標籤後仍指向正確地點。搜尋結果與最愛不得再混用舊兩行卡片、選項膠囊或無框純文字。鍵盤開啟時，全部可見結果需位於鍵盤上方。

目前 Figma 僅為固定資料的靜態 wireframe，不提供選取、收藏、長按、Go 或鍵盤輸入的可執行原型；互動由畫面與文字註記說明。正式 App 仍須從同一份最愛資料更新全部卡片與列表。早先 [選項卡交付紀錄](../../work/design-localgo-v2/oct17-choice-cards/README.md) 屬已撤下原型的歷史紀錄；最新清理與 wireframe 核對見 [本輪紀錄](../../work/design-localgo-v2/oct17-favorite-longpress/README.md)。

## 03 單次路線 wireframe 定案（2026-10-17）

最新指示為**所有模組只做靜態 UI／UX wireframe flow**，不製作 prototype、互動接線、原型測試或多地點組合畫面。本節開始檢視 03 路線，取代前述 02 改版期間「路線留待後續」的範圍記錄；App 尚未依本節實作，畫面與文字不是可執行互動的證據。

### 初始面板與圖示

- **03 單次路線已移除漫步功能**：不提供漫步開關、抵達後隨機選下一站或取消漫步操作。此條取代先前將漫步放入路線細項、與來回走動互斥或載入最愛後保留漫步模式的 03 規則；獨立 05 已依後續指示刪除，漫步統一整合至 06 搖桿，見下節。
- 03 所有畫面的 top bar 固定由左至右為「目前位置／實際狀態 → 播放或暫停 → 齒輪設定」。圖示操作固定在設定左側，原路線草稿／途經點已保留等資料不冒充目前位置；已啟動但無任務時顯示已啟動，暫停圖示停用。有任務才暫停／繼續該任務，不能操作正在瀏覽面板的另一模式。
- **初始／規劃 mode** 保留 mode tab、加入最愛 star、細項入口、起點、有序途經點、目的地、小型新增途經點、最愛路線入口與開始路線。這些編輯工具只在初始 mode 顯示，不放進進行中／暫停面板。
- **從未啟用來回的一般單次路線，進行中面板只含進度、來回走動 checkbox、取消、暫停；暫停面板只含進度、來回走動 checkbox、取消、繼續。** 不顯示 mode tab、路線標題／input、star、細項、新增途經點、最愛路線入口或其他輔助文字。地圖與全域 top bar 保留，底部面板隨內容縮高。
- 來回走動 checkbox 在進行中／暫停都保留，點擊範圍至少 44 pt 高。勾選後依下節 04 顯示「目前位置 %」與同一列的無框方向切換控制；從未啟用來回的一般單次路線使用進度。行進中關閉來回時沿當下方向到下一端點結束，該段保留原 0%／100% 位置軸與目前方向，不切換或歸零。暫停／繼續不重設勾選、方向或目前路線位置。
- **路線自然抵達時**結束本次排程，保留端點模擬位置與已啟動服務，回初始可編輯面板；頂部短暫顯示「路線完成」，不另做完成頁或恢復 GPS。再次開始建立新任務。路線進行／暫停沒有 mode tab，須先取消回初始才能切換其他模式，不新增隱藏模式入口。其他有模式列的情境，切換只瀏覽、明確開始才交接任務。
- 「暫停」保留目前路線任務與進度，切到同結構的暫停面板；「繼續」接續同一任務及進度。**取消路線**則結束本次路線執行，保留起點、目的地、有序途經點與來回設定，回到可編輯的初始 mode。初始 mode 恢復所有編輯入口，修改後按開始路線建立新一次執行；不能以繼續復活已取消的任務。
- **D04 暫停狀態按「取消」先開確認窗**，同狀態 O23 共用此規則。標題「取消這次路線？」；內容「確認後將結束本次路線，回到編輯模式。最後模擬位置與路線草稿會保留。」；操作為「返回」與「確認取消」。開窗不結束任務，維持暫停、原進度及來回設定；遮罩阻擋底層控制。返回或關閉確認窗只回暫停，不自動繼續。只有確認取消才結束本次路線，保留草稿、來回設定與最後模擬位置並回初始 mode。本次新增確認步驟限暫停狀態，進行中規則不變。
- **取消後保留最後模擬位置**，停止本次路線移動，不執行 clear，也不恢復真實 GPS；路線草稿與來回設定保留，回初始 UI 可編輯。取消路線與設定內「停止／恢復原定位」為獨立操作，後者維持既有規則。
- 「＋ 新增途經點」只在初始／規劃面板保留，放在目的地欄位下方，以小型、無框、無底色的文字操作呈現，不使用滿寬的大按鈕；文字 14 pt，透明點擊範圍至少 44 pt 高。路線細項不再重複放大尺寸新增按鈕。新增後以新增途經點作為目前編輯目標，保留既有草稿。
- **路線細項面板只放細部功能**：「已匯入路線」清單按鈕、來回走動及時速滑桿；保留標題與返回。GPX 匯入／匯出按鈕集中在已匯入路線清單內。細項不放起點、途經點、目的地 input、地點 options list、最愛地點入口或新增途經點操作。這些地點 UI 與編輯流程都在初始路線面板及共用地點編輯模式，功能不在初始面板直接展開。已有途經點直接在初始 UI 的單一路線清單依序顯示，不能因精簡細項而被清空。
- 路線細項入口採使用者指定的**滑桿 icon**，點擊範圍至少 44 × 44 pt；全域 Settings 改用**齒輪 icon**。兩者用途分開：滑桿管理目前路線的細項，齒輪進入全域設定。這次統一手機頁現有 Settings 圖示，其他模式的控制內容未調整。
- 靜態 flow：路線主面板 → 滑桿 → 路線細項 → 返回原面板，保留目前草稿與任務狀態。只是移動控制項，不改變既有速度生效、來回走動、原途經點草稿保留或啟動／暫停規則。

### 單一路線清單與地點編輯模式

- **路線節點有效性與清空**：手動路線只保留有效且已確認的地點節點，系統過濾空白／無效節點，不以假座標、模糊地理修正或備援點補齊。編輯沿用草稿／確認／取消；清空已存在的已確認地點值並按確認，等於刪除該節點；取消保留原值。規劃 input 只開 search mode；清空既有值在 search mode 的編輯草稿內提交。只是清除搜尋關鍵字不是刪除已確認地點，非空但無效的輸入不覆寫上一有效節點。刪除／過濾／排序後以剩餘有效節點依序重派第一筆起點、末筆目的地與中間途經點；穩定 ID 跟隨節點，遲到結果不得套入已刪或換位的另一筆。少於兩個有效地點時停用「開始路線／儲存路線」，可繼續編輯，不自動補點。此為最新核可要求，取代先前起終點在資料層不可刪除的限制；路線清單每筆節點右側都提供垃圾桶 icon，起點／途經點／目的地均可直接刪除，不必左滑；刪除後依剩餘有效節點重派角色。GPX raw 軌跡仍依原解析與限制處理，不把這項手動節點過濾規則用來靜默刪除無效 GPX 取樣點。
- **起點、途經點與目的地合併為一張路線清單**，共用單一圓角外框、列間細分隔線。每列中間為上方小字角色（起點／途經點 n／目的地）、下方較大的已確認地點名稱；沒有各列獨立膠囊 input。地點文字區保留原 input 的搜尋入口功能，點一下開啟該節點 search mode，規劃頁不直接輸入。
- Figma 線框清單寬 337 pt、圓角 12 pt；每列 72 pt，角色 13 pt、地點 17 pt。左側把手與右側垃圾桶各有獨立 44 × 44 pt 操作區，18 pt 垃圾桶垂直置中；中間文字區填滿剩餘寬度，長地點名稱單行截斷，完整值保留並可進搜尋查看。正式 App 在 Dynamic Type 下可增高、長清單可捲動，不將 72 pt 當作最大高度。
- **每列最左側保留按住拖動把手**，包含起點、所有途經點與目的地。只有把手啟動排序；中間文字區只進 search mode，右側垃圾桶只刪除對應節點，三個操作區不重疊。依「起點 → 途經點 1／2… → 目的地」排列，沒有途經點時不留空列；「＋ 新增途經點」仍是清單下方小型無框文字操作。
- **所有手動路線可編輯節點都能直接刪除**，垃圾桶固定在各列右側，不依賴左滑，也不加刪除文字按鈕或確認窗。VoiceOver 依角色提供「刪除起點／刪除途經點／刪除目的地」與移動動作；地點區讀出編輯角色與地點名稱。刪除後按剩餘有效節點重派首尾與途經編號，少於兩點停用開始／儲存；新途經點編輯取消丟棄空草稿，遲到結果不得寫入已刪節點。
- 支援整個地點序列重排；放開後依位置重新決定角色：第一筆為起點、最後一筆為目的地，中間依序為途經點 1／2…。地點名稱、座標、標籤及穩定節點身分跟著整筆移動，不能只交換顯示文字或沿用舊索引。
- 拖動中以浮起列、等高佔位與插入位置提示回饋，長列表靠近可見區域邊緣時可自動捲動；放開才套用新的草稿順序，手勢取消恢復拖曳前順序。排序不開始路線、不變更目前模擬位置、不改寫已儲存的最愛路線快照。進行中／暫停面板沒有地點列與把手，須先取消回初始 mode 才可排序。
- 初始 UI **沒有最愛地點按鈕或起點內嵌的最愛捷徑**。初始／規劃 mode 保留「☆ 最愛路線」，進行中與暫停均隱藏此入口；其尺寸、膠囊外框、文字及空心星號導覽樣式對齊 02 的「☆ 最愛地點」。此處空心星號是清單導覽標記；工具列獨立 star 則是開啟新增彈窗的動作，不代表收藏狀態。
- 點擊任一列中間地點文字區，開啟該節點的**search mode／地點編輯模式**，顯示「編輯起點／編輯途經點 n／編輯目的地」標題、強調外框的搜尋 input、輸入鍵盤及取消。此時才呈現編輯狀態；回到初始 UI 後收起鍵盤、options list 與編輯中外觀。
- 輸入名稱、地址或經緯度後，在鍵盤上方顯示地點 options list，沿用 02 的 337 × 56 pt 卡片、單一 title、選取外框／淡底色與右側獨立收藏星號。候選地點的選取與收藏分開，點星號立即改地點最愛，不能確認路線欄位或切換目前編輯目標。有效座標自動選取對應 option，但仍須確認；非空的無效座標不可確認，也不改原路線值；明確清空既有地點值並確認則依節點刪除規則處理，不能與單純清除搜尋關鍵字混用。
- **無輸入或沒有 options 時**提供最愛地點清單入口；空 query／無 options 時顯示「☆ 從最愛選擇目的地」入口，沿用共用選點邏輯；目前編輯角色與穩定節點身分保持，選取仍回填目前欄位，不因入口文案改成編輯終點。進入共用最愛地點清單時保留欄位角色與途經點身分，選取後帶回該欄位的候選地點，經確認才回填。這是選一個地點的入口，不載入整條最愛路線。
- 點 option 只改編輯草稿的候選選取；按「確認」才回填目前欄位並返回**路線初始 UI**，其他有效節點保持原值。既有地點值在編輯草稿中明確清空並確認時刪除該節點，再按剩餘有效節點重派首尾／途經角色；不將清空回填為無效空節點。取消丟棄搜尋與候選草稿，返回原路線，不改原值；取消新途經點編輯時不留下空的途經點。鍵盤完成只收起鍵盤，不能繞過確認。已即時生效的地點收藏操作不因取消而撤銷。
- 開發時以穩定的地點節點身分記錄編輯目標，角色由目前排序決定；起點、目的地或途經點跨角色移動後仍指向同一筆地點。新增、刪除或排序後，不能因索引位移把結果套到另一筆。目標已不存在時須重新選定有效欄位，不能默默改寫目的地。
- **路線起點解析**：明確指定起點優先；動態「目前位置」先用已確認有效的目前模擬位置，沒有時才用有效真實 GPS，不以未確認的最後已知位置充當即時起點。都沒有仍可搜尋／地圖選擇起點，不強迫定位授權。已指定起點與目前位置不同時，按「開始路線」先移至指定起點，再沿既定路線行進；規劃／確認時不移動，也不默默加目前位置到起點的一段。
- **2026-10-17 最新使用者確認：路線地點編輯可用地圖選點 Pin 輸入，Pin 上不顯示 Go。** 點地圖立即以精確經緯度建立候選並填入地點搜尋 input；可取得地名／地址時更新顯示文字及選項，取不到則保留經緯度。反向查詢只補資料，不改點下的座標、候選身分或收藏身分；新輸入／新選取／新地圖點使舊回覆失效。此規則取代先前「路線不使用 Pin」在地點編輯情境的限制。初始、進行及暫停面板仍不增加瞬移 Go；地點編輯只在初始／規劃 mode 進行；確認地點只更新草稿，按開始路線才移動。執行中或暫停時要編輯路線，先按取消回初始 mode，再修改、重新開始。此規則取代較早的「執行中確認搜尋後立即準備改道」與「暫停中直接編輯再繼續」。

最新核可單一路線清單已套用 D02／O24／R06 背景，共 8 筆列；取代先前「角色 header＋各列膠囊 input」。搜尋、確認／取消、清空刪除、有效節點過濾與排序身分規則維持。[Desktop Bridge 讀回與截圖](../../work/design-localgo-v2/oct17-route-list/README.md)。只更新 wireframe 與 docs，App 待實作，無 prototype。

### GPX 匯入與已匯入路線

- **「已匯入路線」清單按鈕放在路線細項**，沿用滿寬膠囊導覽按鈕；GPX 匯入／匯出按鈕放在清單內標題下方，不放在路線細項。初始路線面板不增加此入口；進行中／暫停仍須先取消回初始 mode 才能開啟細項及載入其他路線。
- 清單內的「GPX 匯入」開啟系統檔案選擇。成功解析及儲存後，回清單並選取新紀錄；這一步不覆寫目前草稿、不移動模擬位置，也不自動開始路線。取消檔案選擇不新增；解析失敗顯示錯誤，不留下不完整清單項目，原草稿與清單保持。既有 GPX 格式與解析限制不變。
- 清單保留成功匯入的路線，重新開啟與重啟 App 後仍可取用。每筆有獨立身分，保留來源檔名及完整的有效路線資料與點位順序，不能只存起終點；同名檔案不應默默覆寫其他紀錄。清單與最愛路線分開，匯入不等於加入最愛。
- R07 沿用最愛路線清單的圓角卡片：title 為來源檔名，次行為起點 → 目的地摘要；缺地點名稱時沿用地址／座標備援。右側為獨立 44 × 44 pt 刪除操作，無收藏切換星號。點卡片只更新目前選取，使用強調外框及淡底色，尚未載入草稿。
- 按「載入路線」才將選取紀錄帶回路線初始 mode，載入完整路線與順序，**GPX 在規劃面板只顯示「GPX 路徑」摘要（檔名、點數）並在地圖預覽完整軌跡，不展開為成千上萬個地點 input，也不支援逐點 input／拖曳或轉成手動途經點**；執行保留原軌跡，原解析格式與 10,000 點上限不變。手動路線保持原可編輯序列。保留目前速度與來回設定；仍須按「開始路線」才執行。這不是繼續已取消的舊任務，也不改寫匯入紀錄本身。返回只回路線細項，不套用候選路線。
- 刪除後顯示小型「已刪除／復原」，復原僅恢復該筆獨立紀錄及完整軌跡，不影響其他同內容紀錄；本版採可復原操作，不為常用刪除新增確認窗。若實作不提供復原，必須改採原生確認，不能無保護永久刪除。刪除只移除該筆已匯入紀錄，不刪來源檔案、目前路線草稿或最愛路線，也不改變最後模擬位置。刪除目前選取項目後清除候選選取，須重新選取才能載入。清單為空時顯示「尚未匯入路線」，載入與匯出按鈕停用；保留清單內的 GPX 匯入與返回。長清單可捲動，底部載入操作保持可見。
- 以上為靜態 UI／UX 規格：只增加一張共用清單，不另做空白、錯誤、各檔案組合或系統檔案選擇的 prototype。清單內「GPX 匯出」以目前選取的完整路線為對象，開啟系統分享／儲存；不需要先載入或執行路線，沒有選取時停用。

### 最愛路線

- **初始／規劃 mode 目前路線旁的 star 固定為「加入最愛路線」入口**，點擊開啟彈窗，顯示標籤 input、取消與儲存；彈窗無 mode tab、無收藏切換星號。星號只代表新增動作，不顯示已收藏／未收藏的實心／空心狀態，也不從目前路線或已選清單項目推算收藏狀態。
- 按「儲存」才新增一筆最愛路線，成功後回原路線畫面；取消或關閉不新增。標籤可編輯，未填時沿用起終點的備援顯示規則。**不檢查重複**：同標籤、同起終點、同途經點及順序都可以再次儲存，每次新增獨立紀錄，不合併、不覆寫、不提示重複；儲存後 star 外觀不變。
- 新增紀錄包含完整的起點、目的地與有序途經點，保留各點身分與座標；「目前位置」必須解析為本次確切座標快照，不能儲存動態佔位字串或重載時偷偷改起點。無法解析的目前位置不能當作有效節點儲存，可手選有效地點；依最新過濾規則，以剩餘有效節點重派角色，少於兩點才停用開始／儲存路線。來源為 GPX 時必須保存完整軌跡及類型，不縮成起終點或手動途經點；速度與來回走動設定另行管理，不包含在收藏紀錄。手動路線只保存有效且已確認的節點；空白／無效節點過濾後少於兩個有效地點時不可開始或儲存路線。非空無效編輯不覆寫上一有效節點；既有值清空確認才刪除。新增不改目前路線、目前編輯欄位、模擬位置或定位任務。
- 最愛路線清單保留圓角卡片、起終點資訊與獨立的目前選取外框／淡底色；**沒有收藏實心／空心星號**。已有標籤時用標籤作 title，下一行顯示「起點 → 目的地」；無標籤時直接顯示起終點，不重複文案。缺名稱的地點沿用地址／經緯度備援規則。
- 原本清單內用星號移除路線的操作改成獨立 44 × 44 pt **刪除圖示**。刪除只移除點擊的那筆紀錄；即使另有相同內容的重複紀錄，也不能一併刪除。保留目前載入的路線草稿與定位任務，不清除地點最愛。刪除後提供小型「已刪除／復原」，只復原該筆；若不能復原才採原生確認，不能無保護永久刪除。
- 短按清單卡片載入該筆完整路線並更新清單選取樣式，仍須按開始路線。進行中與暫停面板不提供最愛路線入口，須先取消回初始 mode 才能換路線。清單選取以紀錄身分判斷，不以相同路線幾何合併；「最愛地點」仍只替換目前編輯欄位，與整條路線載入分開。
- 長按既有清單項目仍開啟該筆標籤編輯；編輯頁無星號切換、無 mode tab，底部僅取消／儲存。此處儲存**更新該筆紀錄的標籤**，不呼叫新增流程，也不修改其他同內容紀錄；取消保留原標籤，兩者皆回最愛路線清單。新增彈窗的儲存與既有紀錄編輯的儲存須明確區分。
- 以上取代先前「路線 star 即時加入／移除、依路線內容比對收藏、實心／空心切換」規則。**地點最愛**（包含路線地點編輯 options 的星號）仍維持既有即時收藏與實心／空心規則，本輪不變。

## 04 來回走動 wireframe 定案（2026-10-17）

- **04 是 03 路線勾選「來回走動」後的執行狀態補充**。只保留 [L02／順向](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=13-25459) 與 [L03／逆向](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=13-25502) 兩張靜態 wireframe；不另做規劃、暫停或改目的地副本。
- **方向控制與「來回走動」在同一 row**：左側保留來回 checkbox 與文字，右側是一個**無邊框、無底色**的切換控制，圖示在文字左側，文字顯示目前「順向／逆向」。點一下直接切換另一方向，不使用兩個方向 checkbox、mode tab 或額外方向列。切換控制為 126 × 44 pt，圖示 22 pt；一般單次路線不顯示此控制。關閉來回後走完當前方向的剩餘路段，保留目前方向狀態與原位置軸；該段結束才回初始面板。
- 順向沿起點 → 有序途經點 → 終點；逆向沿同一路徑及反向途經點回原起點。操作從**目前路徑位置**反向行進，不瞬移、不跳至端點、不重建任務或改寫草稿順序；速度與來回勾選保持。勾選來回時抵達端點自動折返，top bar 與切換文字同步顯示實際方向；已關閉來回則依當下方向到下一端點結束。方向操作是獨立命中區，不連帶取消勾選來回。
- **位置條改為「目前位置 %」**：起點固定 0%、終點固定 100%，依整條既定路徑上距起點的累積距離比例表示位置，途經點不重設。順向數值增加、逆向減少；手動改向、暫停或端點折返均不改變當下位置數值。例：42% 處切成逆向仍是 42%，接著往 0% 減少；抵達終點 100% 後逆向遞減，回到起點 0% 後再順向遞增。不是每個方向的完成率，折返時不歸零或轉成 100% 減原值。
- 兩張沿用目前 03 的地圖與 top bar（位置／狀態 → 暫停 → 齒輪）；top bar 顯示「來回路線移動中・順向／逆向」。底部為 190 pt，包含位置條與「0% 起點／100% 終點」標示、同列的來回 checkbox／方向切換、取消／暫停。沒有地點 input、star、細項、額外方向 checkbox 或其他編輯入口。
- **途中取消勾選來回**不跳位置、不改方向，順向走到終點、逆向回起點後結束；剩餘該段維持目前位置百分比（0% 起點／100% 終點）及方向狀態，不歸零或突然改一般完成率。下一次新建一般單次路線才使用一般進度。暫停時取消勾選只改待行規則，仍暫停。
- 暫停／繼續沿用 03，保留路徑位置、方向與勾選；暫停時切換方向只更新待行方向，仍維持暫停，按繼續才移動。暫停後取消沿用 D04a 確認窗，返回仍暫停，確認取消才保留最後模擬位置與完整草稿回初始 mode。編輯、最愛、GPX 與細項沿用 03。
- 靜態驗收：只有順向／逆向兩張，來回均勾選；方向為同列單一無框切換，左圖示右文字且高度至少 44 pt；無方向 checkbox。兩張可示意同一位置 42%，位置條起終點固定，改向不跳變；top bar 與按鈕方向一致。取代先前「方向不可直接控制」「方向 checkbox」「每單程重設進度」規則。未啟用來回的一般 03 畫面維持原進度；關閉來回後剩餘段依上述固定軸與方向收尾，0 prototype 接線；本輪不修改 App、不做互動或實機測試。

## 06 搖桿與自動漫步 wireframe 定案（2026-10-17）

- **刪除 05「漫步：隨機目的地與手動更換」整個 section**（21 張舊畫面）。漫步改為 06 搖桿面板內的 checkbox，不新增第四個 mode tab，也不在 03 路線加回漫步。原 05 獨立規劃、搜尋及取消畫面均不再沿用；手動指定目的地改用本節的「點地圖 → 候選 Pin＋Go」。
- 無可用位置時，搖桿／漫步提供小型「設定起點」入口，沿用 02 選點／Go，完成回 06；起點以已確認模擬位置優先，再用有效真實 GPS，不用未確認最後已知位置或假座標。沒有真實 GPS 只小提示，不強迫授權。
- 06 的四張原畫面均加「漫步」checkbox，至少 44 pt 高，位於模式列下方。未勾選時維持手動搖桿；勾選後啟動自動漫步，以目前模擬位置選取第一個有效目的地，必要的服務準備沿用既有流程，成功後才移動，不以選點等同已到達。
- **漫步啟用時，地圖顯示目前目的地 icon**，與目前模擬位置箭頭分開；Pin 下方不放地點文字；點擊開啟下節的共用地點 card，查看名稱、地址、經緯度並加入最愛。這是目前已套用的漫步目標，沒有 Go；與下述帶 Go 的待確認候選 Pin 分開。不自動將地圖鏡頭移到目的地；既有地圖平移與回中控制保持。
- 抵達目前目的地後自動隨機選下一個不同目的地；也可按「隨機目的地」主動更換，不必等抵達。更新同一個目的地標示並接續移動，舊目的地 icon 不累積。選點範圍沿用舊設計：依目前時速估約十分鐘的移動距離，並避開既有歷史目的地；不是每隔固定時間換點。若無可用目的地，停止自動移動並保留最後模擬位置，顯示原位錯誤供重試，不顯示已到達或持續空轉。
- **漫步啟用後，同一列最右側顯示「隨機目的地」按鈕**，採無框文字樣式，透明操作區 126 × 44 pt；未啟用時隱藏。按一下即重新隨機選取不同於目前目標的有效目的地，成功後替換目前目標及地圖 icon，不增加歷史標記、不改目前模擬位置、速度或漫步勾選，不顯示 Go，也不新增或重啟任務。
- 自動行進中按「隨機目的地」，從目前位置轉向新目標，搖桿與箭頭方向同步更新。手動接管中按下時先更新目標並維持手動控制，放開後才朝新目標自動移動；暫停時只換目標，仍維持暫停，不自動繼續。按鈕與漫步 checkbox 的命中區分開，點按鈕不能取消勾選。選點未成功前保留原目標，失敗時顯示錯誤並保留原狀態；此與已抵達、無下一站可前往的停止情況分開。
- **漫步中可直接點地圖指定新目的地**：點擊空白地圖後顯示一個候選 Pin，上方按鈕寫 **Go**；此時仍朝原目標行進，不立即換目的地或瞬移。再次點地圖只更新同一候選，既有目前目標 icon 保留；不自動重置地圖鏡頭。地圖平移、搖桿拖動及點擊已有 Pin／控制項不視為新選點。
- **按候選 Pin 的 Go 才更換漫步目的地**：從當下模擬位置轉向所選地點，不呼叫瞬移、不跳位置、不重啟任務；保留速度、漫步勾選與既有歷史。成功套用後收起候選 Pin 與 Go，替換原目標 icon，新目標只保留無 Go 的目前目的地 Pin。手動接管時只更新目標，放開搖桿才恢復朝新目標前進；暫停中選點／按 Go 仍維持暫停。套用失敗保留原目標與候選，供重試。
- Pin 明確分兩種 icon：**當前目的地**使用輪廓地標 icon，不帶 Go；**當前點擊地**使用黑點細線 icon，上方帶 Go。點地圖先放當前點擊地 Pin，**再次點擊任一 Pin icon 均開啟該地點 card**（名稱、地址、經緯度與右上 star）；只有 Go 更換漫步目的地。關閉 card 後再點同一 icon 可重開，點另一個 icon 則切換至該地點；查看／收藏不執行 Go。 候選 Pin 仍可即時收藏；點 Pin／card star 不執行 Go。等待 Go 期間若抵達原目標，自動下一站照常，保留待確認候選；主動按「隨機目的地」成功換點時清除待確認候選／Go，失敗則保留；取消勾選或切換到其他執行任務時也清除候選，避免遺留的 Go 改錯任務。
- **自動漫步會連動搖桿方向 UI**：滑塊與目前位置箭頭顯示當下自動行進方向，依地圖旋轉換算至一致的畫面方向。自動更新搖桿外觀只是呈現，不能被當成使用者手勢而切入手動接管。速度仍由既有速度設定管理。
- **漫步中仍可拖動搖桿，暫時接管移動方向**；漫步 checkbox 持續勾選，保留目前目的地與歷史紀錄，不結束或替換漫步任務。手指拖動期間以手動方向為準，自動控制不得同時覆寫移動；滑塊跟隨手指。
- **放開搖桿後恢復自動漫步**，從接管後的目前位置朝目前目的地繼續；搖桿 UI 回到自動行進方向，不能依純手動的放開規則停止漫步，也不跳回接管前位置。手動接管本身不隨機換目的地；若接管期間已抵達，依抵達規則換下一站，放開後朝最新目的地繼續。
- 取消勾選才結束自動選點與自動送點，收起漫步目的地 icon，回手動搖桿，保留最後模擬位置，不呼叫 clear 或恢復真實 GPS。此規則取代舊 05「取消後仍完成當段」；手動拖動／放開不取消勾選。暫停則保留漫步、目的地及位置；已暫停、取消勾選或被其他任務取代時，遲到的放開事件不得重新啟動漫步。設定內停止／恢復原定位維持獨立操作。
- 靜態畫面為 **8 張**（含一張全域 Pin card 共用示例與一張地圖候選／Go 狀態）：D05 手動、D06 漫步中手動接管、J03 暫停、F02 地圖偏移，加 [J04 自動漫步](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=74-48224)、[J05 抵達後下一站](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=74-48285)、[J06 共用地點 card](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=74-48533) 及 [J07 地圖候選／Go](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=74-48634)。一般底部面板由 413 縮為 354 pt，保留模式列、漫步 checkbox／隨機目的地、速度及搖桿；搖桿下方不顯示任何文字說明，包含手機朝向／授權提示、任務延續、漫步接管、抵達下一站與 Pin／Go 操作說明；規則只保留在開發規格及畫布 flow 註記。移除後面板隨內容縮高，不保留文字佔位。不複製原 05 的大量組合狀態。
- 驗收需覆蓋：05 不存在；06 所有搖桿面板在搖桿下方無說明文字、面板隨內容縮為 354 pt 且不留佔位；checkbox 開關、目的地與箭頭分開；自動方向與搖桿 UI 同步；手動接管保持勾選與目的地，放開恢復朝目前目標移動；單純放開不換目標，抵達自動換下一站或按「隨機目的地」主動換目標，舊 icon 消失；按鈕只在啟用時出現於同列最右側，換目標不移動目前位置、不取消漫步、不中斷手動接管或自行解除暫停；點地圖先建立候選＋Go，按 Go 前維持原目標，成功後才替換目前目標並收起 Go；Go 不瞬移、不改速度、不重啟任務，保留手動接管或暫停；兩種 Pin icon 外觀可辨識，當前目的地無 Go、當前點擊地有 Go，再次點任一 icon 都開其自身的地點 card，關閉可重開、切換不混用身分；候選 Pin 可獨立查看／收藏；再次選點、抵達自動下一站、隨機換點、失敗及離開漫步時正確保留或清理候選；取消勾選不恢復 GPS；暫停後放開不自行繼續。以上為待實作驗收的文字規格，不能以靜態畫面認定已完成。

## 共用地圖標示、Pin 與地點 card 定案（2026-10-17）

- **地圖標示統一不帶下方文字**：所有模式的地圖標示 icon 下方均不顯示文字，包含目前模擬位置箭頭、真實 GPS、最後已知／待取得位置、當前目的地與當前點擊地 Pin、移動方向及路線標記。名稱、地址、經緯度由地點 Pin 點擊後的 card 呈現；頂部位置／任務狀態仍保留。瞬移與漫步當前點擊地 Pin 上方的 Go 是操作按鈕，繼續保留；路線地點編輯 Pin 依最新規則不顯示 Go。 此規則適用開發實作與所有主要線框，取代先前只有目的地 Pin 不帶文字的範圍；不改圖示、位置、方向或點擊行為。

- **所有地圖 Pin 都可點擊開啟同一款地點 card**，涵蓋瞬移選點、搜尋／座標候選、最愛帶入、漫步目前目的地／待確認候選，以及其他模式已顯示的地點 Pin。不因此為沒有 Pin 的模式新增標記，也不將目前位置箭頭或地圖回中 icon 當作目的地 Pin。
- 地圖上的目的地 Pin **下方不顯示地點文字**；名稱、地址與經緯度集中在詳情 card。Pin 操作範圍至少 44 × 44 pt，透明擴大命中區不改圖示位置，有 Go 的模式不得與其命中區重疊；路線地點編輯 Pin 沒有 Go。點 Pin 只看詳情，不選另一地點、不瞬移、不換漫步目標或暫停任務；Go 保持獨立操作：02 執行瞬移，06 漫步只更換行進目標。
- Card 採共用白色圓角面板：上方顯示**名稱**，**右上角為獨立 44 × 44 pt 地點最愛 star**；下方依序顯示**地址、經緯度（緯度, 經度）**。無名稱時標題沿用地址／經緯度備援規則，地址未取得時顯示明確的暫無地址／載入狀態，不杜撰資料，仍保留有效座標。完整資料來自點擊 Pin 的地點身分與座標，不以顯示字串識別。
- 地點 star 沿用即時收藏：空心點一下加入並變實心，實心點一下移除並變空心；不需再儲存或編輯 Label。與搜尋選項、最愛列表及座標收藏同步；這是**最愛地點**，不是加入最愛路線。星號操作不關閉 card、不改候選／目前位置／任務，也不冒泡成 Pin 選點或 Go。
- Card 在地圖底部呈現，暫時取代該模式的底部操作區；「關閉」回原面板，保留輸入、候選與移動狀態。全程最多顯示一張 card，點另一個 Pin 才更換內容。查看或收藏不會暫停自動漫步；若任務自動換了目標，已開 card 仍綁定原先點擊的地點，不能悄悄將星號套到新目的地。
- **搜尋 options list 維持單一 title＋右側 star，不增加地址或經緯度副文**；此次完整資訊是 Pin 詳情 card，與既有 337 × 56 pt 搜尋／最愛選項列分開。Label 仍只在最愛清單長按編輯。
- 本次將主流程 25 個可見 Pin 統一為 card 操作範圍，移除 3 個漫步目標標記的下方文字，並新增一張 [J06 共用示例](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/GoFly?node-id=74-48533)。該輪加上示例共 26 個可見 Pin；後續 J07 增加目前目標與候選兩個 Pin，該輪共 28 個；最新 02 再合併重複資料狀態，不再以舊總數表示現況。不為每個地點或星號狀態建立組合畫面。06 現為 8 張，當輪 02／09／11 只套用 Pin 範圍與共用 flow 註記；後續 02 的文案與狀態精簡依本文件最新核可規則。
- 靜態驗收：所有模式地圖標示 icon 下方均無文字（含目前模擬位置箭頭）；頂部狀態與地點 card 資訊保留，Go 僅在該模式允許時顯示（路線地點編輯沒有 Go）；每個已顯示 Pin 的 44 pt 操作範圍可對應正確地點；card 有名稱、地址、經緯度及右上 star；星號即時同步並保留 card 與定位；缺名稱／地址有備援；查不同 Pin、漫步自動換目標時不混用資料；開關 card 不執行 Go。正式互動與資料同步仍須 App 實作及實機驗收，靜態 wireframe 沒有可操作 prototype。

## 07 設定、權限與裝置服務 wireframe 定案（2026-10-17）

- **C01 設定首頁最上方新增「裝置服務」card**，位於「設定」標題下、權限／連線與裝置／說明分組列表之前。標頭顯示目前服務狀態，上方是一個全寬的大尺寸「啟動／停止」按鈕，下方並排「恢復 GPS／重置 VPN 通道」。下方兩個操作僅在停止送點後可用（含初始未啟動）；運作與暫停時顯示停用，執行操作期間互斥。不在每個子頁複製，也不增加狀態排列組合畫面。
- **啟動**只準備及檢查裝置服務，不隱含前往候選 Pin、不開始路線或重播之前任務。服務啟用後，設定 card 同位置改為「停止」；任務暫停時服務尚未停止，也維持「停止」。全域頂部另依任務顯示：未啟動播放只準備、準備中停用、已啟動無任務顯示已啟動且暫停停用、有任務才暫停／繼續既有任務；Go／開始路線／搖桿輸入才開始移動，不操作正在瀏覽的另一面板。服務／通道檢查未通過時保留錯誤或指引，不能只切換外觀當作啟動成功。
- **使用者確認：停止同時恢復 GPS，另保留獨立「恢復 GPS」按鈕。** 停止先結束目前移動、作廢後續送點與遲到回覆，再要求清除模擬定位；**送點狀態與 GPS 恢復狀態分開**：本機送點已停止即可顯示已停止，GPS 仍須清除確認才顯示已恢復；若通道失效或清除回覆不明，顯示「已停止・GPS 待確認」，下方恢復 GPS／重置 VPN 通道仍可用，避免 VPN 失效時無法修復。保留最愛、路線草稿與設定，不能用暫停或取消路線取代。這保留既有 Stop 定義，與 03「取消路線後保留最後模擬位置」分開。
- **恢復 GPS**是可獨立使用的清除／恢復操作，方便停止未完成、位置狀態待確認或仍保留模擬位置時手動重試。操作僅在停止送點後可用；任務運作或暫停時停用，先按大按鈕停止。GPS 待確認不阻擋停止後的手動恢復；未成功或回覆不明不得宣告已恢復。已確認恢復時可安全重按，不建立新的移動任務。手機定位授權仍為選用，不以未授權阻擋要求裝置解除模擬定位。
- **重置 VPN 通道用來手動排除 VPN 失效造成的錯誤／卡住狀態**，僅在本機送點已停止時可用（GPS 待確認仍可用）：作廢遲到回覆，取消舊探測、釋放並重建 GoFly 端的舊 VPN 通道連線，清除暫存錯誤，再實際探測通道可用性。重點修復 LocalDevVPN 顯示 Connected、但 GoFly 無法連線的錯誤；不是控制另一 App 的 VPN 開關，配對與定位服務仍於啟動／Go 確認。這是連線狀態修復，不清除最愛、路線草稿、GPX 或配對身分，不把重置視為已恢復 GPS，也不自動重播／繼續舊任務。檢查完成後由使用者再次啟動。
- 若系統 VPN 未連接、Connected 但通道仍不可用，重置後仍依實際檢查顯示未連接／需修復並提供既有 C05 連接指引；必要時使用者到 LocalDevVPN Disconnect／Connect 再返回檢查。重置不能只把錯誤清成「正常」，也不能宣稱已重連系統 VPN。服務狀態與最後已知位置分開記錄，沒有清除確認時仍保留位置待確認。
- 啟動、停止、恢復與重置共用互斥的執行中狀態，顯示「啟動中／停止中／恢復中／重置中」，避免連點或交錯操作。完成才依結果更新 card 狀態與按鈕；失敗保留可讀原因與重試／VPN 指引。停止、恢復及重置不得被遲到的啟動／送點回覆覆寫。
- C07 搖桿說明依最新確認分開：手動模式放開停止移動；漫步開啟時拖動只暫時接管，放開後**繼續自動漫步**，不因說明頁或操作而清除勾選／目標。
- C05 直接提供「檢查連線／重置 VPN 通道」按鈕，不需先返回設定才能重置；C01 重置入口保留，C06 修復前先停止的說明改指設定頂部停止送點，GPS 待確認時可用恢復 GPS／重置 VPN 通道。權限與背景狀態直接列在首頁；裝置與操作入口改為「裝置資訊／操作說明」。07 舊 prototype 接線撤下，只以主要畫面與本節規格說明流程。
- 靜態驗收：card 在第一個設定分類前；啟動與停止共用全寬大按鈕，下方恢復 GPS／重置並排，運作／暫停時停用、停止送點後才可用；停止會要求恢復 GPS，但「已停止・GPS 待確認」仍可使用兩個修復操作；漫步放開搖桿繼續自動；每個操作至少 44 pt 高，名稱完整可見、內容不超出安全區；啟動不移動、重置不自動恢復 GPS 或重播任務；VPN 檢查未通過不顯示正常；執行中互斥、失敗／未知可重試；07 保留六個 App 主要畫面 C01／C03／C04／C05／C06／C07；系統參考不計入 App 主線，0 prototype 接線。這些是待實作驗收需求，不能以 Figma 靜態畫面認定已修復 VPN 或定位服務。

## Mac 裝置管理自動重新簽名（2026-10-17）

使用者在 Mac App「裝置管理」選擇並成功連線到裝置後，USB／Wi-Fi 皆自動開始該裝置 GoFly App 的重新簽名，保留資料與設定；不要求先按手動重新簽名，也不以到期為觸發條件。現有手動「簽名與重新簽名」入口及流程完整保留，兩入口共用同一操作／進度並防止重複寫入。列表刷新、同一連線事件重送、同一交易內 USB／Wi-Fi 切換不重複觸發。

沿用既有重新簽名前置條件、資料保留及寫入中斷處理；失敗顯示具體原因並可由手動流程重試，不自動改走卸載重裝，不因連線成功就宣告簽名完成。完成後依實際結果更新到期資訊，未知顯示待確認。首次安裝仍維持 USB 限制，這次擴充的是裝置管理的 USB／Wi-Fi 自動續簽入口。

本輪只更新 Mac 開發 docs，不修改 App、Figma 或 prototype；目前 Mac 仍為唯讀檢查／預覽，真實自動與手動重新簽名尚待實作。完整規則及 USB／Wi-Fi、去重、手動入口、失敗／中斷與資料保留驗收見 [Mac 開發規格](../GoFlyMac/DEVELOPMENT.md)。

## C05 VPN 通道操作（2026-10-17 最新補充）

- B01 前景顯示時立即檢查並每 5 秒自動探測，返回 App 立即重查；單次 2 秒逾時。沿用現有通道監測參數作 wireframe 交付規則，離開頁面／進背景停止本頁輪詢，返回重新開始。這不是授予 App 無限背景執行。
- 「檢查連線」是手動立即檢查，固定放在底部「下一步」正上方，間距 12 pt。只允許一筆探測；定時／返回／手動請求共用同一結果，已有探測則合併等待，不排隊或重複請求；遲到／失效結果不覆蓋新狀態。逾時結束等待，可手動重試，自動檢查仍持續。
- 按鈕文字依狀態改為：未連接／失敗「檢查連線」；初次或手動檢查中「檢查中…」；實際可用「連線成功」。連線成功為非互動狀態呈現，同時啟用下一步；背景定時複查保留上一已確認結果，不每 5 秒讓 UI 閃回檢查中。探測失敗／未知則恢復檢查連線並停用下一步；按下一步仍以當下實際探測結果確認才前進，不能略過。
- 設定服務 card 的「重置狀態」正式更名為「重置 VPN 通道」，與恢復 GPS 並排。用途是手動修復 LocalDevVPN 顯示 Connected、但 GoFly 無法連線；僅停止送點後可用（GPS 待確認仍可用），運作／暫停及其他互斥操作中停用。
- 重置取消舊探測與連線、作廢遲到結果、重建 GoFly 端通道並重新實測；不是替使用者切換 LocalDevVPN 的系統 VPN，不清除配對、最愛、路線草稿或 GPX，不代表恢復 GPS，不自動重播或啟動。仍失敗則顯示具體原因，沿用 LocalDevVPN Disconnect／Connect 指引後重試，不能只清錯誤就顯示成功。

驗收包含：不手動點擊仍自動由未連接變成功；手動探測立即觸發或合併同一請求；2 秒逾時不永久等待；成功／中斷時按鈕文案與下一步一致；定時檢查不閃動狀態；Connected 但不可達時可停止送點後重置，成功以探測確認，失敗可修復，原資料與 GPS 待確認狀態保留。只更新靜態 wireframe 與 docs，App 未修改；[最新讀回與狀態示例](../../work/design-localgo-v2/oct17-vpn-poll-reset/README.md)。

## VPN 通道統一與必要確認（2026-10-17 最新定案）

B01、C05 與設定首頁的入口統一顯示「VPN 通道」。VPN 是連線方式，通道可用性是 App 能否使用所需連線的實際結果；UI 合併成一列，不要求使用者理解或分別操作兩個狀態。內部仍可區分診斷原因，畫面不能把另一個 App 的 Connected 字樣當作實測結果。

- 單一狀態：未連接／檢查中／可用／無法連線；結果未知不可顯示可用，錯誤可附具體原因與修復入口。
- B01 不提供略過。回 App 自動探測，亦可按檢查連線；實際可用才啟用下一步，點擊再確認，失敗／未知留頁重試。A02 手機定位仍可略過，兩者門檻不同。
- C05 合併原 VPN 與通道兩列；開啟 LocalDevVPN 下方並排「檢查連線／重置 VPN 通道」兩個明確按鈕，原列表的檢查列移除，避免重複。連線說明／協助保留，所有入口共用同一通道狀態。C01 入口及重置按鈕保留，C06 不加回 VPN 按鈕。
- 既有設定／地圖可保留錯誤處理入口；這不允許首次 B01 繞過通道確認。通道中斷不可送點，啟動／Go 重新確認配對與定位服務的規則維持。

驗收新增：LocalDevVPN 顯示 Connected 但實際通道不可用仍不能下一步；檢查中、失敗、未知均停用；成功後下一步可用、進地圖仍未啟動；只有 A02 保留略過；C05 僅一列 VPN 通道。僅更新 wireframe 與開發 docs，未修改 App 或實機驗收；[最新交付](../../work/design-localgo-v2/oct17-vpn-channel/README.md)。

## 啟動／Go 自動確認與 B01 VPN 引導（2026-10-17 最新定案）

使用者確認：首次開啟 B01 改為「VPN 通道」，移除「裝置／尚未檢查」整列。B01 必須確認實際 VPN 通道可用，不能略過；配對與定位服務則不設首次手動檢查步驟，於啟動／Go 自動確認。

- 按「啟動」或有效候選的「Go」時，自動確認 VPN、配對資料與定位服務是否可用，執行必要準備；不能僅憑首次引導的 VPN 狀態宣告服務就緒。缺少／不符的配對或服務無法連線，共用準備失敗狀態，顯示「配對未完成」「模擬服務無法連線」等具體原因與處理入口；此處服務是送點所需的模擬服務，不能以讀取真實 GPS 失敗觸發。撤下獨立 H03 提示窗。
- 準備期間避免重複請求；失敗／未知不送點、不更新成功位置，保留原候選或任務草稿供修正後重試。無效座標時 Go 仍停用，不以本規則繞過輸入驗證。
- 「啟動」成功只改變服務狀態，不移動；「Go」在準備成功後繼續使用原候選及目前模式的既定操作，不因準備改成固定示例。已啟動後送出 Go 仍須確認通道及必要服務有效，不能沿用過期成功狀態。
- 首次流程 A02 的定位「略過」保留，B01 的必要 VPN 通道不可略過。返回只更新 VPN 通道狀態，不自動跨頁；進地圖前通道可用不代表之後永久有效，啟動／Go 仍須確認。
- C06 只呈現裝置資訊及必要錯誤指引，移除底部 VPN 導覽；設定首頁的 VPN 入口與 C05 保留。

驗收需覆蓋 VPN 已連接但配對缺漏／不符、服務失敗／未知、成功啟動不移動、Go 準備後沿用原候選、重試不重複送點，以及 B01 無裝置檢查、C06 無 VPN 按鈕。這些是最新開發要求，本輪只更新靜態 wireframe 與 docs，尚未修改或驗收 App。Figma 讀回與截圖見 [B01／C06 交付](../../work/design-localgo-v2/oct17-vpn-onboarding/README.md)。

## 真實目前位置不可用：可關閉小提示（2026-10-17 最新修正）

只更新 Figma 靜態 wireframe 與 docs，沒有 prototype 或 App 變更；[最新讀回與截圖](../../work/design-localgo-v2/oct17-optional-real-location/README.md)。

### 08 新任務準備、重試與失敗

- 四個共用狀態：準備中、一次自動重試示例、三次失敗、送點回覆不明／位置待確認；第 2／3 次重試共用同一模板，不另畫兩頁。
- 按啟動、瞬移 Go 或開始新模式任務後，自動確認 VPN 通道、配對與定位服務；不增加支援資料下載步驟。必要裝置準備由 Mac 安裝流程自動完成及驗證；運作時僅檢查並重用已備妥項目，缺少或不相容時指向 Mac 裝置管理修復。**自動重試僅限送點前的準備階段，最多三次嘗試（首次＋兩次重試）**；準備中禁止重複提交。原任務僅在通道與服務仍健康時維持原本運作／暫停；若已中斷，改走 09，不顯示仍在正常移動。準備成功並決定交接新任務時，先停止舊任務後續送點，再啟動新任務；不等待新送點成功才停止舊任務，不允許兩個任務交錯控制。新命令未知不恢復舊任務。
- 保留原操作來源、任務身分、候選／草稿、來回方向及收藏。成功後「啟動」只讓服務可用，不隱含瞬移；Go 才按原模式前往原候選，不能固定台北 101、改投另一候選或重播舊任務。三次失敗保留資料、顯示具體原因，可由使用者修復後明確重試或返回。
- **位置命令送出後，回覆不明不套用準備重試。** 停止繼續送點、保留最後已知位置及候選，先核對實際狀態；O16 與返回地圖都保留 Pin／詳情／收藏，原 Go 停用並顯示「位置待確認」。確認未套用才可明確重試，確認成功則完成原操作；仍未知由設定修復。不新增沒有查詢能力的核對按鈕；使用者停止並作廢舊要求後，才按既有規則開始明確新操作。此鎖定不適用於單純缺少真實 GPS，也不阻擋 H06 啟動準備服務。
- 路線進行中／暫停不可直接編輯地點；先取消回 03 初始 mode，再編輯、重新開始。撤下舊 O26「暫停時準備新目的地」及執行中搜尋改道規則。同模式漫步的 Go 是更換目的地，不重啟任務、不瞬移、不套用跨模式切換流程；暫停中仍維持暫停。

### 09 連線中斷與啟動修復

- 四個共用狀態：VPN 通道未連線、配對／開發者模式具體錯誤、運作中通道中斷、通道恢復但任務仍暫停。H12 支援資料下載失敗撤下，沒有 iOS 首次下載／資料設定步驟。撤下 H03「定位服務無法連線」獨立提示窗，真正模擬服務失敗共用 08 O14 原來源的準備失敗／重試，不因缺少真實位置進入失敗流程。配對／開發者模式共用一個具體原因模板，不用籠統「裝置檢查失敗」。
- 手機定位未允許、讀取失敗或暫無 GPS，僅沿用 02 F07 非模態小提示「目前無法取得真實位置」，右側 × 可關閉；不開 H02／H03 提示窗、不強制設定、不阻擋搜尋、座標、地圖選點、最愛、有效候選 Go 或解除模擬定位。相同情況本次流程關閉後不重複出現，取得位置後移除；不把真實 GPS 納入模擬服務準備／重試門檻。VPN 檢查與重置共用 07 C05；撤下 H04 等重複修復頁。所有入口統一「VPN 通道」與「重置 VPN 通道」，Connected 外觀不能取代實際探測。
- 啟動失敗後保留啟動來源，Go 失敗後保留原候選與模式；開啟外部 App、返回、檢查成功都不直接送點。通道恢復只更新連線狀態，原任務維持暫停；使用者明確按「繼續」且重新確認就緒後，才接續原任務。已停止／取消的任務不能復活，狀態未知則先走 08 核對。
- 配對／開發者模式或裝置準備缺少／不相容，提供 Mac 裝置管理處理入口；不在 iOS 增加下載或額外設定頁。每輪使用者提交的送點前準備最多三次，且同時只有一筆請求；全失敗後由使用者修復並明確重試才建立新一輪，不形成無限自動重試環。

### 10 背景運作與回到前景

- 三個必要狀態：回前景確認中、實際背景中斷後暫停、背景能力未就緒。健康任務回前景直接還原 03／04／06 原 UI 與實際進度、方向、目的地，不新增正常資料副本。背景中斷依原模式沿用暫停 UI 並加短原因：路線／來回用 03／04；漫步用 06 目前目的地與繼續／結束漫步，不出現路線進度／來回 checkbox；手動搖桿釋放輸入，不捏造可繼續的手動方向任務；未知或通道錯誤共用 08／09。
- 路線、來回與自動漫步背景持續仍是產品目標；實際背景機制、VPN／裝置通道及鎖屏送點待實作／實機驗收。系統背景 App 重新整理開啟不等於能力就緒。能力未就緒時在必要處說明背景會暫停並指向 07 C04，不增加重複教學頁。
- 回前景核對同一任務與最後已知位置，不追補背景經過的時間、不重播移動、不因返回就自動啟動。實際背景中斷後須明確繼續；原已暫停／已停止任務維持原狀。
- **App 被終止後重開**不自動送點或重播，保留草稿、最愛與最後已知位置；只有確認仍有效的任務才以暫停供明確繼續，不能確認則走既有待確認／修復。已停止／取消不可復活，不把缺少真實 GPS 誤判為任務中斷。
- 手動搖桿進背景釋放輸入，回前景不回放舊方向或力度。漫步釋放接管後僅在原任務仍有效且健康時繼續自動；已暫停／中斷時不自動恢復。

### 11 停止與恢復定位：共用狀態

- 六個共用狀態：運作／暫停時的設定服務 card、停止送點後等待恢復 GPS、已停止／GPS 待確認、清除確認且 GPS 已取得、清除確認但 GPS 待取得、返回停止後地圖。瞬移／路線／來回方向／搖桿／漫步共用，不保留 41 張模式排列副本。
- 停止只在設定服務 card，結束舊任務並作廢排程、進行中的準備與遲到送點回覆，再要求 clear。**本機送點已停止、裝置清除確認、取得有效 GPS 是三個獨立結果**；本機已停止即可顯示已停止，不沿用 H08「未確認恢復前不顯示已停止」舊規則。
- clear 失敗／逾時／回覆不明時顯示「已停止・GPS 待確認」，「啟動／恢復 GPS／重置 VPN 通道」仍可用；啟動只準備新服務，不移動、不重播，不增加 GPS 先取得的門檻。恢復／重置在運作／暫停時停用，執行操作互斥。重置只修復 GoFly 端 VPN 通道，不清最愛、草稿、GPX、配對或其他使用者資料，不代替恢復 GPS、不控制 LocalDevVPN 開關、不重播任務。
- clear 已確認但未取得有效 GPS 時顯示「模擬已清除／實際位置待取得」，不宣告已取得真實位置；取得有效 GPS 才更新相應狀態。手機定位未授權不阻擋 clear，也不能據此捏造 GPS 或宣稱其他接收 App 已恢復。
- 返回地圖維持停止、保留草稿與最愛；鏡頭不因停止自動置中，不把最後已知位置標為即時 GPS。重新啟動是新操作，不延續已停止任務。03 的取消路線只保留最後模擬位置回初始編輯，與停止／恢復 GPS 分開。
