GoFly adds a verification-only tunnel entry point with no pair-setup fallback.
Patch and reproducible build inputs: app/GoFly/NativeBridge in the source tree.
Full native transitive dependency license inventory and device acceptance are
pending. This development build has not completed a release/distribution audit.

Selected setup codec, protected pairing store and private handoff sources
retain their original author notices. The production native session adapts
only tunnel, identity, DDI and location ownership logic; prototype UI,
debug/JIT wrappers, and phone-side DDI downloader are not compiled in.

See AGPL-3.0.txt for the StikDebug license. Source and audited input hashes are kept in
the development repository at app/GoFly and app/GoFly/NativeSources.json.
