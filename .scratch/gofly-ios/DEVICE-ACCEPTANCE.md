## 票 03：最終手機驗收步驟草案

1. 完成首次流程後直接選有效座標，未先按 Start 即按 Go：應自動完成私有準備與服務準備，再只執行該快照一次。名稱搜尋不選定前不得出現首結果的候選 Pin。
2. 用名稱、座標與地圖點選切換候選；僅選取／拖圖／開詳情不移動兩個接收 App 的位置。輸入超界座標，保留最後有效候選但停用 Go；有效修正或明確選取才恢復。
3. 鍵盤開關、長結果面板及大字級下檢查 Pin 仍在可見地圖中央，Go 在 Pin 上方且可點；詳情與 Go 分別操作，圖示下方沒有文字。
4. Go 成功後比較兩個接收 App 的實際位置；只出現原候選的模擬箭頭、移除原 Pin／Go。準備期間瀏覽新候選時，新候選保留，原快照仍是此次命令目的地。
5. 中斷 LocalDevVPN 測試準備失敗可重試，送點回覆不明時不得自動重送、所有 Go 鎖住；有效 GPS 出現也不得解除命令鎖。明確 Stop 完成後才能建立新操作。
6. 成功或回覆不明後 Stop／Restore：clear 實際確認與有效 GPS 分開，等待時保留最後箭頭半透明，新的有效 GPS 更新後才恢復實心。票 03 改進 clear 協定判斷，需重跑此項，票 01 build 3 的歷史通過不能替代新 native 的真機結果。

上述為待驗步驟，尚未執行，不要求開發期間接手機。
