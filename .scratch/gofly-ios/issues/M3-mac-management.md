# M3：完成 Figma Mac page 的裝置管理與發佈流程

**Status:** in-progress

**Implementation:** in-progress（本機備份與 LocalDevVPN 查詢已接入；續簽、修復、Wi-Fi 寫入與可攜包接續）

**Device verification:** deferred-by-user。全部軟體完成後，使用者統一驗收 Mac 連接手機、安裝 GoFly，再於手機運行。

**Scope:** 依使用者更新的完整 Mac 開發目標，補齊 [Figma Mac page](https://www.figma.com/design/RtPV8PXCQJ2WXK3jk3kPrq/?node-id=21-46408) 的實際功能。M2 的分段排除只限制實作順序，不取消下列需求。

1. 實際讀取簽署身分與到期證據；手動及驗證選定裝置連線後的一次自動續簽共用流程。保留現有 App 資料；不得偷偷改成移除重裝。
2. USB／Wi-Fi 裝置連線、逾時、同機重新連接與配對修復。信任、開發者模式、配對及手機內通道各自核對，不把清單列項當成已連線證據。
3. Wi-Fi 同機重裝／匯入沿用 M2 資料與交易身分，加入明確通道准入及恢復規則；未確定的寫入不能暗中改通道重送。
4. 一般備份管理：已接入實際列表、原裝置綁定、七天保留、確認刪除與中斷接續清理。首次維護觀察到完整成功匯入後開始至少七天保留，未完成不自動刪除；待匯入入口只導回目前原交易，不能刪除唯一復原資料。主要本機流程已驗，手機匯入結果待最終驗收。
5. 首次安裝最後一步核對實際 LocalDevVPN 安裝（已接入唯讀查詢與產品交接介面，待最終整合／手機驗收）。正式 bundle ID 由 Apple metadata 核對；M1 安裝／配對／裝置支援收據仍為獨立技術條件，缺少 VPN 不重做安裝。已安裝 VPN 不代表 VPN 連線、GPS、手機首次流程或移動準備完成。
6. 可攜 Mac 安裝包：解除工作區絕對路徑與目前 venv 依賴，提供版本、架構、最低系統、校驗資訊與清楚的簽署／公證狀態。外部發佈及 Apple 憑證操作須有實際授權；先完成可審查的本機產物。
7. 更新規格、三語文件及集中 Mac＋iPhone 驗收清單。Figma 線框、已實作軟體、離線測試與實機結果分開記錄。

**Development order:** M2 → 資料保留續簽與 USB 修復 → Wi-Fi 管理與重裝 → 備份管理 → 可攜包與跨流程回歸。涉及新的身分、資料與中斷恢復決策時，先取得配置的架構審查核准，再放行限定實作。

**Acceptance:** 實際按鈕對應正式流程與持久化證據，預覽資料不會填入實際成功狀態；受控系統邊界與本機建置／模擬器檢查先完成，實機結果由使用者最後填入。不以 M2 或第18票完成當作整個 Mac 目標完成。

**Backup software evidence:** Mac68項與最後受影響suite6項、Python備份4項及共用M2回歸51項通過。Root用暫存私密資料核對確認刪除、七天到期、持久意圖的中斷接續與未完成保留；實際打包入口於隔離HOME讀取清單，未操作手機。清理先核對完整manifest清單及payload實際大小／雜湊，最後才刪manifest；來源矛盾或變動就保留。實作審查與手機驗收分開，後續管理／發佈功能仍待完成。

**Signing/repair progress:** 完整 v5 設計經配置的 Advisor 第5／5輪核准，見[管理決策](../decisions/M3-management.md)。Core 嚴格請求、來源回報、持久化與前後資料繼承，及 App 啟動／資料持有門檻正在整合驗證；已完成實際 Core→Python→Mac 的完整 Unicode 回報／摘要核對。容量不足、當機歷史回報及後續新 M2 的優先規則一併納入。實際 Mac 管理交易、續簽／修復入口、Wi-Fi 重裝及可攜包接續，尚未提供完整可操作的管理流程或實機證據。

**Control/journal progress:** 固定控制檔入口修訂 v4 已核准；App 前景讀取沿用原資料 owner 門檻，來源取消新增原 PID 核對。Mac 管理交易記錄把選取與操作同次提交，保留未知階段、連線版本及不可變證據，並阻止其他安裝／重裝／備份寫入；歷史 ID 不重用。準備工具沿用實際配對、支援檔及正式回報邊界，修復沒有安裝權限。這些仍是執行器的組件，完整續簽／修復按鈕流程尚待串接。最近未簽署 iOS 編譯通過；模擬器 runner 在 Mach IPC 啟動失敗，未算作 UI 流程通過。

**Mac integration progress:** 已新增管理操作的私密記錄讀取、原筆接續模型、同通道選取紀錄及續簽／配對修復頁。唯讀裝置清單保留兩種通道觀察，介面同機只列一次並預設 USB；使用者可明確選取 Wi-Fi，檢查固定該通道，首次安裝仍只限 USB。自動入口僅接在明確選取後的精確裝置檢查，刷新／重複檢查不觸發。原資料的完整啟動回報、已完成 M2 根與後續管理繼承另有純資料驗證。後端整體執行器及封裝仍在串接，介面與局部檢查通過不代表可用的完整續簽／修復流程。實機仍未驗；本次 Figma Console Desktop Bridge 未連線，沒有宣稱最新畫面對照通過。

**Management integration verification (2026-10-18):** 已接入真正的續行、預先記錄寫入意圖、候選 App 核對、來源控制／舊檔轉換及目標準備。純查詢重新解碼完整正式回報、配對／支援及 Core 繼承關係，不以階段標記宣告完成。持久核對請求有界保留32次提交；只在原通道版本、明確接續及實際不存在時重送相同資料，未知更新／配對／正式寫入不盲目重送。遺失首次核對 PID 時不接管其他程序，只有完整原筆回報與兩次實際程序不存在觀察一致才建立獨立缺席檢查；正式啟動仍須事前意圖。規格及實作雙軸審查的具體問題已關閉。Root 離線 Mac72／Python155 項通過，並對最後解碼修正補跑受影響檢查；實際 bundle36個資源、10份管理來源與隔離記錄查詢一致。這些是軟體與封裝證據，實際手機流程、最新 Figma 視覺對照、Wi-Fi M2、可攜 DMG 及最終三語交付仍待完成，整票保持 in-progress。
