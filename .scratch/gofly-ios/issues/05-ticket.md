# 05: 地點最愛、長按標籤與共用 Pin 詳情

**Status:** ready-for-agent

**Blocked by:** 03。

**What to build:** 搜尋或點 Pin 查看地點並即時收藏；從最愛重選或長按改標籤，重開仍保存。

**Design reference:** 02 K01／K02／K04／D18、06 J06。

**Acceptance criteria:**

- [ ] 星號與選取各有獨立命中區；收藏依地點身分與座標，星號立即持久化且跨畫面同步，不改候選、位置或任務。
- [ ] 最愛短按選取、長按編輯；儲存／取消只處理標籤草稿並回原清單，星號的即時變更不因取消標籤而回滾；未收藏停用標籤儲存。
- [ ] 任一已顯示 Pin 開同款名稱／地址／座標 card；最多一張，關閉回原面板。card 綁點擊時的地點，不因目標更新把收藏套到另一點；持久化失敗不假稱已保存。

**Verification:** 原子儲存與損壞資料保護測試；選取／長按／星號不冒泡 UI 驗收；重開讀回。
