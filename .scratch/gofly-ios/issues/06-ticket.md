# 06: 兩點路線：開始、暫停、取消與自然完成

**Status:** ready-for-agent

**Blocked by:** 04。

**What to build:** 確認起終點後開始移動，能暫停繼續、取消回編輯或自然到達。

**Design reference:** 03 D02／D03／D04／D04a、REF03。

**Acceptance criteria:**

- [ ] 正式路線草稿與任務分開；起終點透過共用 search mode 確認回填，取消不改值；起點使用明確指定位置或已確認模擬位置／有效 GPS，無位置可手選。
- [ ] 明確開始才先移至指定起點再走，規劃不動、不偷偷增加接近起點路段；暫停／繼續保留同一任務進度。
- [ ] 運作／暫停只有精簡控制、沒有模式及編輯入口；暫停取消先確認。取消保留草稿及最後模擬位置、不 clear；自然完成回初始並保留端點與服務。

**Verification:** 排程／起點／進度與取消測試；實機驗證路徑及接收端位置。
