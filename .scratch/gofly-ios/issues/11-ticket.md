# 11: 手動搖桿與可選起點

**Status:** ready-for-agent

**Blocked by:** 04。

**What to build:** 設定有效起點後，用方向、力度與時速控制移動，放開停止該次手勢。

**Design reference:** 06 D05／F02。

**Acceptance criteria:**

- [ ] 已確認模擬位置優先，再用有效 GPS；完全無位置顯示小型設定起點，共用 02 選點／Go 後回搖桿，未授權不阻擋。
- [ ] 方向、力度、速度與箭頭一致；放開結束手動送點、保留最後模擬位置，不等同停止服務／clear。
- [ ] 只有一個送點擁有者；暫停、停止、通道中斷、進背景都釋放輸入；遲到手勢／回覆不重啟或回放。

**Verification:** 方向／力度／速度／取消競態測試；實機搖桿與回中操作。
