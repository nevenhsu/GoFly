# M2：同機重新安裝與所選資料保留

**Status:** in-progress

**Implementation:** in-progress

**Device verification:** deferred-by-user（全部開發完成後集中手機驗收）。

**Blocked by:** M1 軟體門檻已於 a116a3c 完成；實機延後不阻擋開發。完整 v8 與來源／接收／交易介面已核准，依序實作中。

**What to build:** 使用者在 Mac 明確選取最愛、路線、設定後，先取得 iOS 已停止且實際 clear 確認的安全資料快照；Mac 完整驗證、同步並重新讀回備份後，才允許同機移除及重新安裝。iPhone 在所有所選類別、簽署／準備資料與新本機復原記錄完成前保持 O10 鎖定。

- [ ] 最愛保留地點身分、精確座標、原始順序與標籤；路線保留完整手動節點、GPX 分段／重複點、記錄 UUID、檔名、草稿與路線速度；設定只含已儲存的語言、外觀、模式、來回及搖桿速度。
- [ ] 三類別全部 8 種選取組合都明確處理，含全部不選；未選資料由重新安裝清除，不暗中保留。
- [ ] 匯出只接受正常地圖、無未結束編輯／選取、無運作中或尚未返回的實體工作、實際服務停止與 clear 已確認。未達條件就說明原因，不自動 Stop、clear、儲存或關閉編輯。
- [ ] 同一份私密原子匯出紀錄先提交 preparing 鎖；此時沒有完成或移除權限。複製失敗仍維持鎖定，完整來源驗證後才轉 ready；沒有被 root 引用的孤立 cutline 不得重寫 Session。Mac 備份驗證在移除之前；移除意圖後不可放棄／解鎖，必須先取得 App 的封存回報才能終止及移除。
- [ ] 安裝結果不明不可接管或重送；還原類別指標與收據同次提交，重播不重複匯入、不覆寫後續修改、不復活舊任務。重新開啟維持同一交易並由 Mac 明確繼續。
- [ ] 舊 App 沒有接收器時顯示需要先更新，保留原 App／資料；不宣稱有替代無損更新能力。未決 M1 阻擋 M2，不改寫未知安裝擁有權。
- [ ] 本分段先完成 USB 同機重裝；自動續簽、Wi-Fi、配對修復、備份管理及可攜 Mac 發佈包接續於完整 Mac 開發範圍，不因本分段排除而取消。跨裝置移轉、prototype 搬遷與 iOS 下載／U19 仍不在範圍。

**Implementation record:** 資料格式、唯讀來源快照、公開協定及八個 owner 鎖定分段已實作，原始審查問題已修正並完成獨立讀回。Root 對停止變動的來源執行 Core XCTest65＋Swift Testing412＋Transport9，共486項通過；Mac47及 Python Reinstall25項通過，M1 Python57項回歸通過，跨語言原始回覆 bytes 一致。這些是分段資料／協定／鎖定證據，不代表來源 App、移除、安裝或裝置結果。Mac 正式重裝頁、交易讀回與程序生命週期已接入工作樹，完整 Mac58項及新增設定綁定1項離線測試通過；共用驗證器實際程序5項通過。持久化與 producer 的整合缺口仍在修正，App 整合尚未放行，沒有新的 M2 App 完整建置／安裝成果，不宣稱跨端重裝完成。分段變更保留工作樹待整合。

**Verification:** 公開生產介面失敗斷言、真實暫存檔／故障注入、跨語言原始 bytes、受控系統邊界、完整套件與未簽署建置、O10 負向／不完整資料模擬器、雙軸審查；最終軟體結果另記，真實同機重裝與接收 App 效果留集中驗收。
