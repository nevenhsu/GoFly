# 集中 Mac＋iPhone 驗收草案

使用者指定所有軟體開發完成後才統一驗收：先用 Mac 連接手機、安裝 GoFly，再於手機運行。本文件是待驗計畫，不是功能完成或裝置通過紀錄；目前不要求連接手機。最終版本、建置與軟體證據交付時補入。

## Mac 到手機的順序

1. 從最終 Mac 安裝包開啟，核對版本、架構、系統及必要環境。工作區／開發 venv 不應成為發佈版隱藏依賴；簽署與公證狀態須如實呈現。
2. 首次安裝只選原 USB iPhone，核對信任、開發者模式、Team 與實際簽署資訊後明確開始。中斷時重新查詢原交易；不把同 Bundle 的未知安裝接管為成功。
3. 核對 GoFly 安裝、本次配對匯入及必要裝置支援的獨立回報；最後的產品流程再核對 LocalDevVPN 已安裝。已安裝 VPN 不代表已連線、有效 GPS 或移動服務可用。
4. 在手機完成正常首次流程，驗證 Start 不改位置、Stop／恢復 GPS 保留等待中的半透明無圓框箭頭，有效 GPS 到達才更新並恢復實心。其餘手機流程依[集中手機驗收](DEVICE-ACCEPTANCE.md)。

## 裝置管理與資料

- USB／Wi-Fi 清單同機去重且優先 USB；完成實際連線核對才進管理。手動與每次已核實連線的一次自動續簽共用同一操作，不重複送出，保留既有資料。身分不符或結果未知時保留待確認狀態。
- 配對修復、信任、開發者模式與手機本機通道分別核對。中斷後使用原手機與原交易恢復；未知寫入不偷偷換通道或重送。
- 用可丟棄的測試最愛、手動／GPX 路線、已接受草稿及設定驗證同機重裝：全選、只保留路線、全部不選三個代表情境。八種組合另由離線測試覆蓋。未勾選資料應被清除，位置、任務及 native 資格不還原。
- 重裝只在來源 App 已停止、clear 確認且關閉編輯後准入。準備或備份失敗後仍停在 O10；Mac 明確放棄並收到 App 釋放回報後才解鎖。沒有 ready 與完整持久化備份，不進移除。
- 還原中重開 App 仍鎖定；每類別收據與進度跟原交易一致。全部完成後核對原始順序、標籤、精確座標、GPX 分段／重複點及草稿速度。重播舊交易不得覆寫後續修改或重新啟動移動。
- 備份管理分清完成／未完成與原裝置；成功匯入後保留七天，未完成不自動刪除。確認刪除只影響允許刪除的本機已完成副本。

無法在硬體安全重現的未知安裝、遲到回覆或提交故障，如實記未驗；不要求為本清單破壞裝置檔案。舊 prototype 沒有正式接收器時，應保留來源並提示需要更新，不能把此情境宣稱為已驗證的無損搬遷。

結果紀錄至少包含 Mac／iPhone 系統、GoFly Mac／iOS 版本、通道、原交易識別、實際顯示、接收 App 位置結果及待驗項。三語、深色、大字級與 VoiceOver 結果另依手機清單記錄。
