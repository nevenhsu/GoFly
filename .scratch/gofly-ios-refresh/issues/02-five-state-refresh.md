# 02: 三模式五態 pill 與 5 秒探測穩定刷新

**Status:** implemented; software-verified

**Blocked by:** 01：建立三模式共用狀態投影與刷新基準。

**What to build:** 週期性連線檢查期間，三模式與設定頁顯示穩定而一致的任務狀態；重連結果與後續自動修復狀態均能如實顯示。

- [ ] 三模式與設定頁 pill 精確使用「啟動（灰）／模擬中（綠）／暫停（黃）／停止（灰）／錯誤（紅）」；正常探測 pending/success 不切換既有任務態。
- [ ] 啟動、模擬中、暫停、停止均保有連線 session；停止只停止模擬，不等同 disconnect。驗證實際 session 與畫面語意一致，不能只改文字。
- [ ] 首次未知、手動檢查及設定頁必要的檢查進度仍能如實表達；禁止重複檢查及操作資格維持原規則。
- [ ] 自動探測及已斷線時的週期重試統一以上輪完成後 5 秒排程；虛擬時鐘驗證滿 2 秒不探測、滿 5 秒才探測，且不重疊。首次／回前景與手動檢查仍按資格立即排程，busy 延後結束後正確重新排程。
- [ ] 定位送點、probe timeout、ACK 期限與補間時序不因檢查間隔改變；送點故障立即處理。
- [ ] 覆蓋三模式、冷啟動、檢查失敗／逾時／取消及快速前後景，晚到結果不能覆寫新一代狀態。
- [ ] 健康狀況至少連續 30 秒不出現因週期性探測造成的 pill 往返；同步規格與驗收。
